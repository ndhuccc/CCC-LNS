S1 · 引起動機 · MOTIVATE

機器學習三步曲：點菜·試吃·找廚神 Three Steps — Hypothesis, Scoring, Search

全章靈魂一句話：在候選選單裡找讓評分最低的那道菜。Soul in one line: find the dish with lowest score on the menu.

1

假設類別 $\mathcal{F}$ Menu

餐廳賣什麼菜？線性模型 = 義大利麵專賣；神經網路 = 分子創意餐廳。所有候選函式的集合 $\mathcal{F}$ 即選單。Linear = pasta shop; neural net = molecular gastronomy.

2

評分機制 $S(f)$ Critic

毒舌評論家打分：差越多分越高（損失大），越好吃分越低。目標是讓損失最小。Bigger gap = higher loss; want minimal.

3

搜尋策略 Search in Fog

在迷霧大山找最低山谷：梯度下降像盲人摸象，一步步往下走到碗底。Foggy mountain: gradient descent steps to valley.

公式 · 一句話翻譯

$$\hat{f} := \arg\min_{f \in \mathcal{F}} S(f)$$

「最佳模型 $\hat{f}$ 就是在選單 $\mathcal{F}$ 裡找讓評分 $S(f)$ 最低的那一個。」Best model = lowest scoring dish on the menu.

直覺 · 翻譯秘訣

$:=$ 是「定義為」、$\arg\min$ 是「讓最小的引數」、$f \in \mathcal{F}$ 是「在選單裡」。$:=$ defines, $\arg\min$ = arg achieving min.

三大武功家族 Three Families

像武俠小說的少林武當峨眉：有老師、沒老師、社會滾打。Like Shaolin/Wudang/Emei: supervised, unsupervised, RL.

有老師

監督式 Supervised

帶標籤考卷，寫錯立刻糾正。

分類·格子派：貓/狗、及格/不及格Cats vs dogs, pass/fail.

迴歸·數線派：房價、分數Price, score — continuous.

沒老師

丟 100 張無標籤照片，自己找模式。

分群：像的湊一坨Cluster similar.

降維：行李箱壓成紙片Suitcase → paper.

社會滾打

強化學習 Reinforcement

不給考卷，丟進環境「棍棒教育」。

Agent 過程：$s$狀態亂 → $a$收拾 → $r$糖果State $s$ messy → action $a$ tidy → reward $r$.

跌倒被電（負獎）、放對給糖（正獎）Fall = shock, tidy = candy.

S2 · 核心幾何 · GEOMETRY

Perceptron 線性切割 vs XOR 非線性侷限 Linear Cut vs Non-linear Limit

第一次 AI 冬眠的核心幾何鐵證：一條直線能切 AND，卻切不開 XOR。Core geometry of first winter: line cuts AND, not XOR.

matplotlib 精準：AND 線性可分 vs XOR 非線性不可分 Precise geometry

左 $x_1+x_2=1.5$ 一刀切開 (1,1)；右四角對角同類——任何直線均切不開 · Left cuts; right diagonally inseparable.

為何 AND 可 Why AND Works

僅 (1,1) 為 1，其餘為 0，一條 $x_1+x_2=1.5$ 剛好分離。Only (1,1)=1, line $x_1+x_2=1.5$ separates.

為何 XOR 不可 Why XOR Fails

$(0,1)/(1,0)=1$ vs $(0,0)/(1,1)=0$ 對角同類，任何直線均包裹錯誤。Diagonal same class — no line.

S2 · 邏輯·學習·梯度 · LOOP

邏輯開、學習與最佳化迴路 Logic, Learning & Gradient Loop

M-P 神經做邏輯開（AND/OR/NOT）→ Hebb 一起放電一起接線→ ADALINE 梯度下降追求誤差最小。M-P logic → Hebb wiring → ADALINE gradient.

邏輯開預設假設，Hebb 給學習哲學，梯度完成搜尋 · Logic sets hypothesis, Hebb inspires learning, gradient completes search.

連動關鍵

M-P 證明神經可邏輯，Hebb 提出相關性學，ADALINE 以梯度讓搜尋可收斂。M-P proves logic, Hebb proposes correlation, ADALINE makes search convergent.
