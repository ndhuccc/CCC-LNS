S1 · 引起動機

什麼叫「監督」？What is Supervised Learning?

人情世故 · Human Story

大一新生需要學長姐指路：哪裡是陷阱、哪裡是捷徑。機器也一樣，需要「帶標籤的老師（資料集）」。Freshmen need seniors; models need labeled teachers.

定義 · Definition

監督式學習 = 用「輸入 $x_i$ + 正確答案標籤 $y_i$」成對餵養，讓 $f_\theta$ 學會「看到新輸入就答對」。Learn from input–label pairs to answer unseen inputs.

沒有標籤的隨機照片堆，不會讓電腦頓悟；有標籤的 5 碗拉麵 + 5 碗滷肉飯才會。Random pile ≠ learning; labeled examples do.

直覺 · Intuition

盔甲 $\mathcal{R}^d$、$\ell_1$、$f_\theta$ 只是記號；骨子裡是「老師指著答案教你」。Notation is armor; essence is teacher pointing at answer.

分類：教電腦認拉麵與滷肉飯Classification: Teach Ramen vs Braised Pork

Fig 1 · 離散格子 vs 連續數線 (discrete grids vs continuous line)

任務定義 · Task

$$f_\theta: \mathbb{R}^d \to \{\ell_1, \dots, \ell_k\}$$

把每個東西分到預先定義好的、有限的「離散格子」裡。Map input to one of $k$ discrete boxes.

例：$\{\text{蘋果, 黃瓜, 拉麵, 滷肉飯}\}$、$\{\text{資工, 電機}\}$。E.g. {apple, cucumber, ramen, braised pork}.

怎麼教 · How to Teach

收集 5 碗標記「拉麵」、5 碗標記「滷肉飯」，指著說「這是拉麵、這是滷肉飯」，讓電腦從「有沒有湯、碗形、鋪料」等特徵 (Features)學心法 $f_\theta$。Show 5+5 labeled bowls; model learns features → rule.

回歸：教電腦估考試成績Regression: Estimate Exam Score

任務定義 · Task

$$f_\theta: \mathbb{R}^d \to \mathbb{R}$$

依據特徵預測一個「連續」實數值：$y_i \in \mathbb{R}$（如 $78.5$ 分）。Predict a continuous real value.

特徵 $x_i$ (Features)

每週讀書時數、缺課堂數、打電動時數Study hrs, absences, gaming hrs.

標籤 $y_i\in\mathbb{R}$

0∼100 間任意實數（78.5），非有限格子Any real 0–100, not a box.

電腦學會「讀書時數↔分數」連結，新學期狀態丟進去就吐出預測分數。Model links features to score; new input → predicted value.

關鍵差異：格子派 vs 數線派Key Difference: Grids vs Line

分類 格子派 (Discrete)

  • 輸出：離散、有限標籤 $\{\ell_1,\dots,\ell_k\}$finite labels
  • 像：分系所「資工/電機」which department
  • 問的是「是哪一類？」“which class?”

回歸 數線派 (Continuous)

  • 輸出：連續、無限實數 $\mathbb{R}$infinite reals
  • 像：成績 88、價格 150.2、長度 7.388, 150.2, 7.3
  • 問的是「是多少？」“how much?”

別混淆 · Don’t Mix

餐廳是「賣拉麵還是估房價」根本不同工種；輸出型態決定任務型態。Ramen shop vs appraisal — different jobs; output type decides.

同一個模型，兩種視角：共享 $s(\mathbf{x})=x_1+x_2$Same Model, Two Views: Shared s(x)

共享線性分數 · Shared Score — $\theta=(1,1,0)$

$$s(\mathbf{x}) = 1\cdot x_1 + 1\cdot x_2 + 0 = x_1 + x_2$$

12 個點 $\mathbf{x}\in\mathbb{R}^2$ 共用此分數，但「怎麼用分數」決定任務。Same score, different use → different task.

分類加門檻 (Threshold)

$$f_{\text{cls}}(\mathbf{x}) = \begin{cases} \ell_2 & s(\mathbf{x})\ge 0 \\ \ell_1 & s(\mathbf{x})<0 \end{cases}$$

硬分黑白，只剩 $\ell_1/\ell_2$。Hard split → only $\ell_1/\ell_2$.

回歸直接輸出 (Direct)

$$f_{\text{reg}}(\mathbf{x}) = s(\mathbf{x}) \in \mathbb{R}$$

保留連續值 3.5∼16.0。Keep continuous 3.5–16.

注意 · Note

此例 12 點皆 $s\ge0$ 故全 $\ell_2$；若有 $s<0$ 則落 $\ell_1$（黑色 X）。決策邊界 $x_1+x_2=0$ 為通過原點斜率 $-1$ 的虛線。12 pts all $\ge0$ → all $\ell_2$; boundary $x_1+x_2=0$ through origin.

一句話對比 · One-liner

同一數學 $s(\mathbf{x})=x_1+x_2$，分類「問格子」把連續壓成離散，回歸「問數線」保留連續。Same math; classification bins it, regression keeps it.
