KP-1：狀態空間模型 (SSM) 導論與序列建模演進

1. 序列建模的第三條道路：SSM 的崛起

在深度學習發展歷程中，序列數據（文字、語音、時間序列、影像）的處理長期由 RNN/LSTM（第 8 章） 與 Transformer/Attention（第 9 章） 兩大陣營主導。然而，RNN 存在無法平行化訓練與長距離記憶退化的缺陷，而 Transformer 則面臨著二次方時間與記憶體複雜度 $\mathcal{O}(n^2)$ 的推理瓶頸。

狀態空間模型（State Space Models, SSMs） 作為源自控制理論與系統工程的經典數學工具，近年在深度學習領域展現出強大威力。從 2021 年的 S4 (Structured State Space) 到 2023–2024 年的 Mamba 與 Mamba-2，SSM 成功結合了 RNN 的線性推理效率 $\mathcal{O}(n)$ 與 Transformer 的高效平行訓練能力，成為長序列建模的革命性架構。

2. 從 S4 到 Mamba 的演進歷程

SSM 在語言與序列任務上的突破經歷了三個關鍵節點：

  • S4 (Structured State Space, 2021)：引入對角加上低秩 (DPLR) 矩陣結構與 Cauchy 核技巧，首次在長距離推論基準 (LRA) 上取得突破，並實現 $\mathcal{O}(n \log n)$ 的平行卷積訓練。
  • H3 與 DSS (2022)：進一步簡化矩陣結構，並將 SSM 與自注意力層結合，逐步填補 SSM 與 Transformer 在自然語言處理上的性能差距。
  • Mamba (2023–2024)：提出選擇性機制 (Selective Mechanism)，讓狀態矩陣與採樣步長 $\Delta$ 隨輸入動態變化（Content-Aware），實現了媲美 Transformer 的語言建模能力與百萬級 Token 的超長文本處理。

KP-2：SSMs 的六大核心優勢分析

1. SSMs 相較於 Transformer 與 RNN 的六大優勢

相較於傳統自注意力機制與循環神經網絡，狀態空間模型 (SSMs) 具備六大顯著的數學與工程優勢：

  1. 高效長距離依賴處理 (Efficiency)：利用 Fast Fourier Transform (FFT) 或 Mamba 的選擇性掃描，時間複雜度由 Transformer 的 $\mathcal{O}(n^2)$ 降低至 $\mathcal{O}(n \log n)$ 甚至 $\mathcal{O}(n)$。
  2. 卓越的長跨度記憶衰減控制 (Long-Range Retention)：透過連續時間特徵值 $\boldsymbol{\lambda}$ 的精確參數化，訊息可以在極長的時間步（如整個圖書或數萬步音訊）中無損傳遞。
  3. 極低的推理記憶體需求 (Lower Memory Footprint)：自迴歸生成時不需要維護龐大的 KV Cache，僅需維護固定大小的隱藏狀態 vector $\boldsymbol{h}_t$。
  4. 高度 GPU 平行化能力 (Parallelization)：在訓練階段可轉化為 1D 因果卷積，完美發揮現代 GPU 的張量平行運算。
  5. 對非均勻/不規則採樣數據的天然強健性 (Robustness to Irregular Sampling)：源自連續時間微分方程式 $\boldsymbol{h}'(t) = \boldsymbol{A}\boldsymbol{h}(t) + \boldsymbol{B}\boldsymbol{x}(t)$，可任意調整時間步長 $\Delta$ 處理缺測或非定頻傳感器數據。
  6. 數學可解釋性與系統診斷能力 (Interpretability)：狀態轉移矩陣 $\boldsymbol{A}, \boldsymbol{B}, \boldsymbol{C}, \boldsymbol{D}$ 具有明確的動態系統特徵值、頻響與穩定性幾何意義。

KP-3：Transformer 與 RNN 的序列瓶頸對比

1. Transformer 的二次方計算壁壘

在 Transformer 的自注意力層中，長度為 $n$ 的序列需要計算 Query 與 Key 的全對全相似度矩陣 $\boldsymbol{Q}\boldsymbol{K}^\top \in \mathbb{R}^{n \times n}$。雖然在訓練時可透過全矩陣運算實現高度 GPU 平行化，但在生成推理階段，生成第 $t$ 個 Token 必須重新與前 $t-1$ 個 Token 計算注意力，計算量隨著序列長度呈二次方 $\mathcal{O}(n^2)$ 暴增。

2. 傳統 RNN 的遞迴失憶與訓練瓶頸

傳統 RNN（如第 8 章所述）的隱藏狀態更新為：

$$\boldsymbol{h}_t = \sigma(\boldsymbol{W}\boldsymbol{h}_{t-1} + \boldsymbol{U}\boldsymbol{x}_t), \quad \boldsymbol{y}_t = \boldsymbol{V}\boldsymbol{h}_t$$

RNN 的推理時間複雜度為 $\mathcal{O}(1)$，但由於非線性激活函數 $\sigma$ 與狀態遞迴鎖定，前向傳播無法在時間軸上進行 GPU 平行運算；且矩陣連乘易導致嚴重的梯度消失，無法保留長距離上下文。

3. SSM 的雙重視角：同時融合平行與遞迴

SSM 的關鍵突破點在於：線性連續系統具備對偶表示（Duality）！在訓練時它可以寫成全平行 1D 卷積，在推理時它可以寫成單步線性遞迴，完美兼顧兩者的優點。

KP-4：連續時間狀態空間模型 (Continuous SSM) 方程式

1. 源自現代控制理論的連續微分方程

狀態空間模型 (SSM) 最初建立於連續時間空間 $\mathbb{R}$，將輸入信號 $\boldsymbol{x}(t) \in \mathbb{R}^d$ 透過隱藏狀態 $\boldsymbol{h}(t) \in \mathbb{R}^s$ 映射至輸出信號 $\boldsymbol{y}(t) \in \mathbb{R}^p$。其數學結構由一組常微分方程 (Ordinary Differential Equations, ODEs) 所定義：

$$\begin{align} \boldsymbol{h}'(t) &= \boldsymbol{A} \boldsymbol{h}(t) + \boldsymbol{B} \boldsymbol{x}(t) \tag{狀態方程式} \\ \boldsymbol{y}(t) &= \boldsymbol{C} \boldsymbol{h}(t) + \boldsymbol{D} \boldsymbol{x}(t) \tag{輸出方程式} \end{align}$$

2. 四大參數矩陣的物理與幾何意義

  • $\boldsymbol{A} \in \mathbb{R}^{s \times s}$：狀態轉移矩陣 (State Transition Matrix)。控制系統內部隱藏狀態的自我演化與記憶保留衰減率（特徵值決定系統穩定性與頻響）。
  • $\boldsymbol{B} \in \mathbb{R}^{s \times d}$：控制矩陣 (Control/Input Matrix)。決定外部輸入信號 $\boldsymbol{x}(t)$ 如何驅動與寫入隱藏狀態。
  • $\boldsymbol{C} \in \mathbb{R}^{p \times s}$：輸出矩陣 (Output Matrix)。將隱藏狀態 $\boldsymbol{h}(t)$ 提取並映射回觀測輸出空間。
  • $\boldsymbol{D} \in \mathbb{R}^{p \times d}$：直通矩陣 (Feedthrough Matrix)。代表輸入到輸出的直接跳躍連線（Skip Connection），在許多離散模型中常簡化為零矩陣 $\boldsymbol{D}=\mathbf{0}$。

KP-5：離散時間 SSM 與卷積視角 (Convolutive View)

1. 離散化狀態空間方程式

由於電腦處理的文字與數位信號均為離散序列 $\{x_0, x_1, \dots, x_n\}$，連續微分方程必須經過離散化處理。離散時間 SSM 表示為：

$$\begin{align} \boldsymbol{h}_t &= \overline{\boldsymbol{A}} \boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}} \boldsymbol{x}_t \\ \boldsymbol{y}_t &= \overline{\boldsymbol{C}} \boldsymbol{h}_t \end{align}$$

其中 $\overline{\boldsymbol{A}}, \overline{\boldsymbol{B}}, \overline{\boldsymbol{C}}$ 為離散化後的參數矩陣。

2. 遞迴展開與卷積對偶性 (Convolutive View)

假設初始狀態 $\boldsymbol{h}_0 = \mathbf{0}$，我們逐步展開時間步：

$$\begin{aligned} \boldsymbol{h}_1 &= \overline{\boldsymbol{B}} \boldsymbol{x}_1 \\ \boldsymbol{h}_2 &= \overline{\boldsymbol{A}}\overline{\boldsymbol{B}}\boldsymbol{x}_1 + \overline{\boldsymbol{B}}\boldsymbol{x}_2 \\ \boldsymbol{h}_3 &= \overline{\boldsymbol{A}}^2\overline{\boldsymbol{B}}\boldsymbol{x}_1 + \overline{\boldsymbol{A}}\overline{\boldsymbol{B}}\boldsymbol{x}_2 + \overline{\boldsymbol{B}}\boldsymbol{x}_3 \\ &\vdots \\ \boldsymbol{y}_t &= \overline{\boldsymbol{C}} \sum_{i=1}^t \overline{\boldsymbol{A}}^{t-i} \overline{\boldsymbol{B}} \boldsymbol{x}_i = \sum_{i=1}^t \left(\overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^{t-i} \overline{\boldsymbol{B}}\right) \boldsymbol{x}_i \end{aligned}$$

這表明：離散 SSM 的輸出 $\boldsymbol{y}_t$ 等價於輸入序列 $\boldsymbol{x}$ 與長期卷積核 $\boldsymbol{K}$ 的 1D 因果卷積！

KP-6：雙線型法 (Bilinear Method / Tustin) 離散化推導

1. 梯形積分與雙線型變換 (Tustin's Method)

如何將連續參數 $\boldsymbol{A}, \boldsymbol{B}$ 轉化為離散矩陣 $\overline{\boldsymbol{A}}, \overline{\boldsymbol{B}}$？數值分析中最常用的是雙線型變換（Bilinear Transformation / 梯形法則）。

考慮狀態微分方程在時間區間 $[t_n, t_{n+1}]$（步長為 $\Delta$）上的梯形積分：

$$\boldsymbol{h}_{n+1} - \boldsymbol{h}_n = \frac{\Delta}{2} \left( \boldsymbol{h}'(t_{n+1}) + \boldsymbol{h}'(t_n) \right) = \frac{\Delta}{2} \left( (\boldsymbol{A}\boldsymbol{h}_{n+1} + \boldsymbol{B}\boldsymbol{x}_{n+1}) + (\boldsymbol{A}\boldsymbol{h}_n + \boldsymbol{B}\boldsymbol{x}_n) \right)$$

2. 精確代數移項與離散矩陣公式

假設在微小步長 $\Delta$ 內輸入平滑 $\boldsymbol{x}_{n+1} \approx \boldsymbol{x}_n$，經由代數移項整理：

$$\left(\boldsymbol{I} - \frac{\Delta}{2}\boldsymbol{A}\right) \boldsymbol{h}_{n+1} = \left(\boldsymbol{I} + \frac{\Delta}{2}\boldsymbol{A}\right) \boldsymbol{h}_n + \Delta \boldsymbol{B} \boldsymbol{x}_{n+1}$$

兩邊左乘逆矩陣 $\left(\boldsymbol{I} - \frac{\Delta}{2}\boldsymbol{A}\right)^{-1}$，求得離散矩陣：

$$\begin{align \overline{\boldsymbol{A}} &= \left(\boldsymbol{I} - \frac{\Delta}{2}\boldsymbol{A}\right)^{-1} \left(\boldsymbol{I} + \frac{\Delta}{2}\boldsymbol{A}\right) \\ \overline{\boldsymbol{B}} &= \left(\boldsymbol{I} - \frac{\Delta}{2}\boldsymbol{A}\right)^{-1} \Delta \boldsymbol{B} \\ \overline{\boldsymbol{C}} &= \boldsymbol{C} \end{align}$$

KP-7：結構化狀態空間 (S4) 卷積核與輸出表示

1. S4 模型的核心使命

雖然離散 SSM 可化為卷積，但若直接計算 $\overline{\boldsymbol{A}}^i$，對於長度為 $L$ 的序列，計算 $\overline{\boldsymbol{A}}^1, \overline{\boldsymbol{A}}^2, \dots, \overline{\boldsymbol{A}}^L$ 的矩陣次方代價極高（矩陣乘法 $\mathcal{O}(s^3 L)$）。

2021 年提出的 Structured State Space (S4) 模型透過對 $\boldsymbol{A}$ 矩陣施加結構化約束，打破了這一計算瓶頸。

2. S4 的 1D 長距離因果卷積核

S4 將整個序列的映射簡化為一維長距離因果卷積：

$$\boldsymbol{y}_k = \sum_{i=0}^k \boldsymbol{K}[i] \boldsymbol{x}_{k-i} = (\boldsymbol{K} * \boldsymbol{x})_k$$

其中卷積核 $\boldsymbol{K} \in \mathbb{R}^L$ 的第 $i$ 個元素定義為：

$$\boldsymbol{K}[i] = \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^i \overline{\boldsymbol{B}}$$

一旦快速生成卷積核 $\boldsymbol{K}$，即可透過快速傅立葉變換 (FFT) 在 $\mathcal{O}(L \log L)$ 時間內完成全序列計算！

KP-8：S4 卷積核推導與展開證明

1. 從零初始狀態進行符號遞迴展開證明

設初始隱藏狀態 $\boldsymbol{h}_0 = \mathbf{0}$，根據離散遞迴式 $\boldsymbol{h}_{k+1} = \overline{\boldsymbol{A}}\boldsymbol{h}_k + \overline{\boldsymbol{B}}\boldsymbol{x}_k$：

$$\begin{aligned} \boldsymbol{h}_0 &= \mathbf{0} \\ \boldsymbol{h}_1 &= \overline{\boldsymbol{B}}\boldsymbol{x}_0 \\ \boldsymbol{h}_2 &= \overline{\boldsymbol{A}}\overline{\boldsymbol{B}}\boldsymbol{x}_0 + \overline{\boldsymbol{B}}\boldsymbol{x}_1 \\ \boldsymbol{h}_3 &= \overline{\boldsymbol{A}}^2\overline{\boldsymbol{B}}\boldsymbol{x}_0 + \overline{\boldsymbol{A}}\overline{\boldsymbol{B}}\boldsymbol{x}_1 + \overline{\boldsymbol{B}}\boldsymbol{x}_2 \\ &\vdots \\ \boldsymbol{h}_k &= \sum_{i=0}^{k-1} \overline{\boldsymbol{A}}^{k-1-i} \overline{\boldsymbol{B}} \boldsymbol{x}_i \end{aligned}$$

2. 代入輸出方程式與變數代換 (Re-indexing)

將 $\boldsymbol{h}_k$ 代入輸出方程式 $\boldsymbol{y}_k = \overline{\boldsymbol{C}}\boldsymbol{h}_k$：

$$\boldsymbol{y}_k = \overline{\boldsymbol{C}} \left( \sum_{i=0}^{k-1} \overline{\boldsymbol{A}}^{k-1-i} \overline{\boldsymbol{B}} \boldsymbol{x}_i \right) = \sum_{i=0}^{k-1} \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^{k-1-i} \overline{\boldsymbol{B}} \boldsymbol{x}_i$$

令 $j = k - 1 - i$，則當 $i=0$ 時 $j=k-1$；當 $i=k-1$ 時 $j=0$：

$$\boldsymbol{y}_k = \sum_{j=0}^{k-1} \left(\overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^j \overline{\boldsymbol{B}}\right) \boldsymbol{x}_{k-1-j} = \sum_{j=0}^{k-1} \boldsymbol{K}[j] \boldsymbol{x}_{k-1-j}$$

這嚴謹證明了 S4 的遞迴形式與 1D 因果卷積形式在數學上完全等價！

KP-9：S4 狀態轉移矩陣 (DPLR) 與 Woodbury 矩陣恆等式

1. 對角加上低秩 (DPLR) 矩陣結構

單純對角矩陣 $\overline{\boldsymbol{A}} = \operatorname{diag}(\boldsymbol{\Lambda})$ 雖易求次方，但無法捕捉狀態維度間的相互作用；而全矩陣則運算太慢。S4 提出了對角加上低秩（Diagonal Plus Low-Rank, DPLR）結構：

$$\overline{\boldsymbol{A}} = \operatorname{diag}(\boldsymbol{\Lambda}) + \boldsymbol{P}\boldsymbol{Q}^\top$$

其中 $\boldsymbol{\Lambda} \in \mathbb{C}^s$，低秩矩陣 $\boldsymbol{P}, \boldsymbol{Q} \in \mathbb{C}^{s \times r}$ ($r \ll s$)。

2. 拉普拉斯變換與 Woodbury 矩陣恆等式求逆

在頻域中，SSM 的傳遞函數 (Transfer Function / Resolvent) 為 $\boldsymbol{H}(z) = \overline{\boldsymbol{C}}(z\boldsymbol{I} - \overline{\boldsymbol{A}})^{-1}\overline{\boldsymbol{B}}$。利用 Woodbury 矩陣恆等式：

$$(z\boldsymbol{I} - \overline{\boldsymbol{A}})^{-1} = \left(z\boldsymbol{I} - \operatorname{diag}(\boldsymbol{\Lambda}) - \boldsymbol{P}\boldsymbol{Q}^\top\right)^{-1} = \boldsymbol{D}_z^{-1} + \boldsymbol{D}_z^{-1}\boldsymbol{P} \left(\boldsymbol{I} - \boldsymbol{Q}^\top\boldsymbol{D}_z^{-1}\boldsymbol{P}\right)^{-1} \boldsymbol{Q}^\top\boldsymbol{D}_z^{-1}$$

其中 $\boldsymbol{D}_z = z\boldsymbol{I} - \operatorname{diag}(\boldsymbol{\Lambda})$ 為對角矩陣，求逆僅需 $O(s)$ 對角線倒數！這使得卷積核可在極短時間內精確算得。

KP-11：Mamba 自適應選擇性狀態空間模型 (Selective SSM)

1. 傳統 SSM (S4) 的盲點：時不變性 (LTI) 限制

S4 雖然高效，但其參數矩陣 $\overline{\boldsymbol{A}}, \overline{\boldsymbol{B}}, \overline{\boldsymbol{C}}$ 是固定不變的（Linear Time-Invariant, LTI）。這意味著不論輸入是小說、程式碼還是隨機雜訊，卷積核 $\boldsymbol{K}$ 都一模一樣，無法根據當前輸入內容選擇性地過濾或記憶資訊 (Content-Aware Selection)。

2. Mamba 選擇性機制 (Selective Mechanism)

2023 年提出的 Mamba 作出了重大突破：將採樣步長 $\Delta_t$、控制矩陣 $\boldsymbol{B}_t$ 與輸出矩陣 $\boldsymbol{C}_t$ 轉化為當前輸入 $\boldsymbol{x}_t$ 的動態函數！

$$\begin{align \boldsymbol{B}_t &= \text{Linear}_B(\boldsymbol{x}_t) \\ \boldsymbol{C}_t &= \text{Linear}_C(\boldsymbol{x}_t) \\ \Delta_t &= \text{Softplus}\left(\text{Parameter} + \text{Linear}_\Delta(\boldsymbol{x}_t)\right) \\ \overline{\boldsymbol{A}}_t &= \exp(\Delta_t \boldsymbol{A}) \\ \overline{\boldsymbol{B}}_t &= (\Delta_t \boldsymbol{A})^{-1} (\exp(\Delta_t \boldsymbol{A}) - \boldsymbol{I}) \cdot \Delta_t \boldsymbol{B}_t \end{align}$$

3. 離散選擇性更新與門控融合

Mamba 時間步更新結合了自適應門控 (Hardware-Aware Selective Scan Algorithm)：

$$\boldsymbol{h}_t = \mathbf{f}_{\text{gate}}(\boldsymbol{x}_t) \odot \left( \overline{\boldsymbol{A}}_t \boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}}_t \boldsymbol{x}_t \right), \quad \boldsymbol{y}_t = \boldsymbol{C}_t \boldsymbol{h}_t$$

這使得 Mamba 能夠在輸入極長文本時，動態決定「忘記雜訊」或「寫入關鍵資訊」，在語言建模上全面媲美 Transformer！

KP-12：測試時訓練 (TTT) 圖層：將隱藏狀態模型化為線上學習者

1. TTT (Test Time Training) 層的核心哲學

2024 年提出的 TTT (Test Time Training) Layers 提出了全新的視角：將隱藏狀態 $\boldsymbol{h}_t$ 本身看待為一個小的微型神經網絡模型 $\theta_t$！

在傳統 SSM 中，隱藏狀態更新是線性線性矩陣相乘 $\boldsymbol{h}_t = \overline{\boldsymbol{A}}\boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}}\boldsymbol{x}_t$；而在 TTT 中，隱藏狀態更新被替換為在測試/推理時間進行線上自監督梯度下降更新！

2. TTT 層的三大核心步驟與算式

  1. 隱藏模型預測 (Hidden Model Prediction)： $$\hat{\boldsymbol{z}}_t = f_t(\boldsymbol{x}_t; \boldsymbol{\theta}_t)$$ 其中 $f_t$ 為以 $\boldsymbol{\theta}_t$ 為權重的微型神經網絡（如 FNN）。
  2. 自監督重建損失 (Self-Supervised Loss)： $$\ell_t = \mathcal{L}\left( \hat{\boldsymbol{z}}_t, \tilde{\boldsymbol{x}}_t \right)$$ 其中 $\tilde{\boldsymbol{x}}_t$ 為自監督受損或預測目標。
  3. 線上梯度更新 (Online Test-Time Gradient Update)： $$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla_{\boldsymbol{\theta}_t} \ell_t$$

這表明：SSM 只是 TTT 的特例（當 $f_t$ 為線性、學習率 $\eta=0$ 時）。TTT 代表了自適應隱藏狀態（如 DeltaNet, Titans）的未來發展趨勢。

KP-13：注意力機制與狀態空間模型 (SSM) 的對偶矩陣等價性證明

1. 線性 Transformer (Linear Attention) 回顧

注意力機制與 SSM 是對立的嗎？答案是否定的！2024 年研究證明兩者具有深厚的數學對偶性 (Mathematical Duality)。

在線性 Transformer 中，將 Softmax 相似度替換為核函數 $\phi(\boldsymbol{q}_t)^\top \phi(\boldsymbol{k}_i)$，輸出為：

$$\boldsymbol{y}_t = \frac{\sum_{i=1}^t \phi(\boldsymbol{q}_t)^\top \phi(\boldsymbol{k}_i) \boldsymbol{v}_i^\top}{\sum_{i=1}^t \phi(\boldsymbol{q}_t)^\top \phi(\boldsymbol{k}_i)} = \frac{\phi(\boldsymbol{q}_t)^\top \sum_{i=1}^t \phi(\boldsymbol{k}_i) \boldsymbol{v}_i^\top}{\phi(\boldsymbol{q}_t)^\top \sum_{i=1}^t \phi(\boldsymbol{k}_i)}$$

2. 無歸一化線性核下導出 SSM 形式

定義矩陣狀態累加量 $\boldsymbol{H}_t := \sum_{i=1}^t \phi(\boldsymbol{k}_i) \boldsymbol{v}_i^\top$。改寫為遞迴加法模型：

$$\boldsymbol{H}_t = \boldsymbol{H}_{t-1} + \phi(\boldsymbol{k}_t) \boldsymbol{v}_t^\top$$

取線性核 $\phi(\boldsymbol{q}) = \boldsymbol{q}, \phi(\boldsymbol{k}) = \boldsymbol{k}$ 並省去分母歸一化，輸出可寫為：

$$\begin{align} \boldsymbol{H}_t &= \boldsymbol{H}_{t-1} + \boldsymbol{k}_t \boldsymbol{v}_t^\top \\ \boldsymbol{y}_t &= \boldsymbol{q}_t^\top \boldsymbol{H}_t \end{align}$$

這與 SSM 的離散狀態更新 $\boldsymbol{h}_t = \overline{\boldsymbol{A}}\boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}}\boldsymbol{x}_t$ 及輸出 $\boldsymbol{y}_t = \overline{\boldsymbol{C}}\boldsymbol{h}_t$ 結構完全同構！ 這證明了注意力機制與 SSM 是同一數學本質的兩面表示。

1. 單一主線類比：汽車行駛的物理動態

把 Continuous SSM 想像成一台行駛中的汽車：

  1. 輸入 $\boldsymbol{x}(t)$：是你腳踩油門或煞車的力道（外部驅動信號）。
  2. 隱藏狀態 $\boldsymbol{h}(t)$：是汽車當前的車速與引擎轉速（系統內部蓄積的狀態）。
  3. 輸出 $\boldsymbol{y}(t)$：是儀表板上顯示的時速數字與儀表指針（對外展現的觀測值）。

2. 鷹架式拆解：兩大連續時間方程式

連續 SSM 由一組常微分方程 (ODE) 所定義：

  1. 狀態方程式 (State Equation)： $$\boldsymbol{h}'(t) = \boldsymbol{A} \boldsymbol{h}(t) + \boldsymbol{B} \boldsymbol{x}(t)$$
  2. $\boldsymbol{h}'(t)$：隱藏狀態隨時間的變化率（變化速度）。
  3. $\boldsymbol{A} \in \mathbb{R}^{s \times s}$：狀態轉移矩陣，決定內部記憶的自我衰減與震盪頻率。
  4. $\boldsymbol{B} \in \mathbb{R}^{s \times d}$：控制矩陣，決定當前輸入 $\boldsymbol{x}(t)$ 如何影響隱藏狀態。
  5. 輸出方程式 (Output Equation)： $$\boldsymbol{y}(t) = \boldsymbol{C} \boldsymbol{h}(t) + \boldsymbol{D} \boldsymbol{x}(t)$$
  6. $\boldsymbol{C} \in \mathbb{R}^{p \times s}$：輸出矩陣，將隱藏狀態提取映射為觀測輸出。
  7. $\boldsymbol{D} \in \mathbb{R}^{p \times d}$：直通矩陣（Feedthrough），代表直接跳躍連線（Skip Connection）。

3. 數值演算示範：手算純量 ODE 解析解

假設純量情況 $s=1, d=1, p=1$： 設 $A = -2.0, B = 1.0, C = 1.0, D = 0$。初始狀態 $h(0) = 0$。

給定階躍輸入 $x(t) = 1.0$ ($t \ge 0$)： $$\begin{align*} h'(t) &= -2 h(t) + 1.0 \\ \Rightarrow h(t) &= \frac{1}{2} \left(1 - e^{-2t}\right) \end{align*}$$

  • 當 $t = 0$ 時，$h(0) = 0$。
  • 當 $t = 0.5$ 時，$h(0.5) = 0.5 (1 - e^{-1}) \approx 0.316$。
  • 當 $t \to \infty$ 時，$h(t) \to 0.5$（指數收斂至穩態值！）。

  2. 時間步展開 ($h_0 = 0$)： $$\begin{align*} \boldsymbol{h}_1 &= \overline{\boldsymbol{B}} \boldsymbol{x}_1 \\ \boldsymbol{h}_2 &= \overline{\boldsymbol{A}}\overline{\boldsymbol{B}}\boldsymbol{x}_1 + \overline{\boldsymbol{B}}\boldsymbol{x}_2 \\ \boldsymbol{h}_3 &= \overline{\boldsymbol{A}}^2\overline{\boldsymbol{B}}\boldsymbol{x}_1 + \overline{\boldsymbol{A}}\overline{\boldsymbol{B}}\boldsymbol{x}_2 + \overline{\boldsymbol{B}}\boldsymbol{x}_3 \\ \boldsymbol{y}_t &= \overline{\boldsymbol{C}} \sum_{i=1}^t \overline{\boldsymbol{A}}^{t-i} \overline{\boldsymbol{B}} \boldsymbol{x}_i = \sum_{i=1}^t \left( \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^{t-i} \overline{\boldsymbol{B}} \right) \boldsymbol{x}_i \end{align*}$$
  3. 因果卷積定義： $$\boldsymbol{y}_t = (\boldsymbol{K} * \boldsymbol{x})_t \quad \text{其中 } \boldsymbol{K}[i] = \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^i \overline{\boldsymbol{B}}$$

3. 數值演算示範：4 時間步數值完全對齊

設純量參數 $\overline{A} = 0.5, \overline{B} = 1.0, \overline{C} = 2.0$。輸入序列 $x = [1, 2, 0, 0]$。

  • 方法 1：單步遞迴計算：
  • $h_1 = 0.5(0) + 1(1) = 1 \Rightarrow y_1 = 2(1) = 2.0$
  • $h_2 = 0.5(1) + 1(2) = 2.5 \Rightarrow y_2 = 2(2.5) = 5.0$
  • $h_3 = 0.5(2.5) + 1(0) = 1.25 \Rightarrow y_3 = 2(1.25) = 2.5$
  • $h_4 = 0.5(1.25) + 1(0) = 0.625 \Rightarrow y_4 = 2(0.625) = 1.25$
  • 方法 2：卷積核計算 ($K[i] = 2.0 \times 0.5^i \times 1.0$)：
  • $K = [2.0, 1.0, 0.5, 0.25]$
  • $y_1 = K[0]x_1 = 2.0 \times 1 = 2.0$
  • $y_2 = K[0]x_2 + K[1]x_1 = 2.0(2) + 1.0(1) = 5.0$
  • $y_3 = K[0]x_3 + K[1]x_2 + K[2]x_1 = 0 + 1.0(2) + 0.5(1) = 2.5$
  • $y_4 = 0 + 0 + 0.5(2) + 0.25(1) = 1.25$

兩種方法數值完全精確吻合！

問：為什麼卷積核 $K[i] = \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^i \overline{\boldsymbol{B}}$ 中的 $i$ 稱為「滯後時間 (Lag)」？ 答：因為 $i$ 代表該輸入距離當前時間步隔了多久！離當前越遠 ($i$ 越大)，乘以的 $\overline{\boldsymbol{A}}^i$ 次方越高，衰減越嚴重。

1. 單一主線類比：用梯形面積取代光滑曲線

想像你要計算曲線下的面積：

  1. 歐拉法 (Euler Method) 用矩形去硬貼，誤差很大。
  2. 雙線型法（Tustin 法則）：用「梯形」把相鄰兩點 $t_n$ 與 $t_{n+1}$ 連起來求面積！這樣既精確，又不會像高階積分那樣引發數值振盪。

2. 鷹架式拆解：代數移項精確推導

考慮 ODE $h'(t) = A h(t) + B x(t)$，在長度為 $\Delta$ 的時間區間內進行梯形積分：

  1. 梯形積分公式： $$h_{n+1} - h_n = \frac{\Delta}{2} \left( h'(t_{n+1}) + h'(t_n) \right) = \frac{\Delta}{2} \left( (A h_{n+1} + B x_{n+1}) + (A h_n + B x_n) \right)$$
  2. 假設輸入平滑 ($x_{n+1} \approx x_n$) 整理： $$h_{n+1} - \frac{\Delta}{2} A h_{n+1} = h_n + \frac{\Delta}{2} A h_n + \Delta B x_{n+1}$$
  3. 提出同類項與矩陣求逆： $$\left(I - \frac{\Delta}{2}A\right) h_{n+1} = \left(I + \frac{\Delta}{2}A\right) h_n + \Delta B x_{n+1}$$ $$h_{n+1} = \left(I - \frac{\Delta}{2}A\right)^{-1} \left(I + \frac{\Delta}{2}A\right) h_n + \left(I - \frac{\Delta}{2}A\right)^{-1} \Delta B x_{n+1}$$
  4. 定義離散矩陣： $$\begin{align*} \overline{\boldsymbol{A}} &= \left(\boldsymbol{I} - \frac{\Delta}{2}\boldsymbol{A}\right)^{-1} \left(\boldsymbol{I} + \frac{\Delta}{2}\boldsymbol{A}\right) \\ \overline{\boldsymbol{B}} &= \left(\boldsymbol{I} - \frac{\Delta}{2}\boldsymbol{A}\right)^{-1} \Delta \boldsymbol{B} \end{align*}$$

3. 數值演算示範：手算離散矩陣

設純量 $A = -2.0, B = 1.0$，採樣步長 $\Delta = 0.1$：

  1. 計算中間求逆項： $$I - \frac{\Delta}{2} A = 1.0 - \frac{0.1}{2} (-2.0) = 1.0 + 0.1 = 1.1$$ $$\left(1.1\right)^{-1} = \frac{1}{1.1} \approx 0.90909$$
  2. 計算 $\overline{A}$： $$I + \frac{\Delta}{2} A = 1.0 + 0.05(-2.0) = 1.0 - 0.1 = 0.9$$ $$\overline{A} = \frac{0.9}{1.1} = \frac{9}{11} \approx 0.81818$$
  3. 計算 $\overline{B}$： $$\overline{B} = \frac{0.1 \times 1.0}{1.1} = \frac{0.1}{1.1} = \frac{1}{11} \approx 0.09091$$

離散化後的轉移矩陣 $\overline{A} \approx 0.818 < 1$，系統嚴格保持穩定！

2. 鷹架式拆解：五大證明步驟

我們一步步拆解課本 Section 4.2 的證明：

  1. 設定初始條件：設初始隱藏狀態 $\boldsymbol{h}_0 = \mathbf{0}$。
  2. 遞迴展開隱藏狀態： $$\begin{align*} \boldsymbol{h}_1 &= \overline{\boldsymbol{B}} \boldsymbol{x}_0 \\ \boldsymbol{h}_2 &= \overline{\boldsymbol{A}} \overline{\boldsymbol{B}} \boldsymbol{x}_0 + \overline{\boldsymbol{B}} \boldsymbol{x}_1 \\ \boldsymbol{h}_k &= \sum_{i=0}^{k-1} \overline{\boldsymbol{A}}^{k-1-i} \overline{\boldsymbol{B}} \boldsymbol{x}_i \end{align*}$$
  3. 代入輸出方程式： $$\boldsymbol{y}_k = \overline{\boldsymbol{C}} \boldsymbol{h}_k = \sum_{i=0}^{k-1} \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^{k-1-i} \overline{\boldsymbol{B}} \boldsymbol{x}_i$$
  4. 索引變換 (Re-indexing)：
  5. 令 $j = k - 1 - i$。當 $i=0$ 時 $j = k-1$；當 $i=k-1$ 時 $j=0$。
  6. 原式變為： $$\boldsymbol{y}_k = \sum_{j=0}^{k-1} \left( \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^j \overline{\boldsymbol{B}} \right) \boldsymbol{x}_{k-1-j}$$
  7. 定義卷積核與結論：
  8. 定義 $\boldsymbol{K}[j] := \overline{\boldsymbol{C}} \overline{\boldsymbol{A}}^j \overline{\boldsymbol{B}}$，即得 $\boldsymbol{y}_k = (\boldsymbol{K} * \boldsymbol{x})_k$！得證。

1. 單一主線類比：快速通關特約通道

想像你要通過機場海關（矩陣求逆）：

  1. 普通全矩陣：每個人都要人工排隊查驗護照，耗時 $O(s^3)$。

2. 鷹架式拆解：DPLR 結構與 Woodbury 求逆

  1. 對角加上低秩 (DPLR) 矩陣結構： $$\overline{\boldsymbol{A}} = \operatorname{diag}(\boldsymbol{\Lambda}) + \boldsymbol{P}\boldsymbol{Q}^\top$$
  2. $\boldsymbol{\Lambda} \in \mathbb{C}^s$：對角矩陣特徵值。
  3. $\boldsymbol{P}, \boldsymbol{Q} \in \mathbb{C}^{s \times r}$：秩為 $r \ll s$ 的低秩修正矩陣。
  4. 拉普拉斯頻域傳遞函數 (Resolvent)： $$\boldsymbol{H}(z) = \overline{\boldsymbol{C}} (z\boldsymbol{I} - \overline{\boldsymbol{A}})^{-1} \overline{\boldsymbol{B}}$$
  5. Woodbury 矩陣恆等式展開： $$(z\boldsymbol{I} - \operatorname{diag}(\boldsymbol{\Lambda}) - \boldsymbol{P}\boldsymbol{Q}^\top)^{-1} = \boldsymbol{D}_z^{-1} + \boldsymbol{D}_z^{-1}\boldsymbol{P} \left(\boldsymbol{I} - \boldsymbol{Q}^\top\boldsymbol{D}_z^{-1}\boldsymbol{P}\right)^{-1} \boldsymbol{Q}^\top\boldsymbol{D}_z^{-1}$$
  6. 其中 $\boldsymbol{D}_z = z\boldsymbol{I} - \operatorname{diag}(\boldsymbol{\Lambda})$ 為對角矩陣，其求逆 $\boldsymbol{D}_z^{-1}$ 僅需對角元素取倒數 $O(s)$！

  • Woodbury 恆等式求逆 FLOPs： $$\text{FLOPs} \approx s + r^3 + s = 128 + 1 + 128 = 257 \quad (\text{僅需 257 次運算！})$$

運算效率提升了整整 8160 倍！

  1. 訓練階段（電影後期特效渲染）：拿到了整部電影的所有腳本（全序列 $x_0..x_{n-1}$），使用 1D FFT 卷積進行全片平行渲染。

2. 鷹架式拆解：雙重執行模式細節

  1. 訓練模式 (Training Mode - FFT 卷積)：
  2. 快速生成卷積核 $\boldsymbol{K} \in \mathbb{R}^L$。
  3. 利用快速傅立葉變換： $$\boldsymbol{y} = \mathcal{F}^{-1} \left( \mathcal{F}(\boldsymbol{K}) \odot \mathcal{F}(\boldsymbol{x}) \right)$$
  4. 時間複雜度：$\mathcal{O}(L \log_2 L)$，高度 GPU 平行。
  5. 推理模式 (Inference Mode - 單步遞迴)：
  6. 時間步更新： $$\boldsymbol{h}_t = \overline{\boldsymbol{A}}\boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}}\boldsymbol{x}_t, \quad \boldsymbol{y}_t = \overline{\boldsymbol{C}}\boldsymbol{h}_t$$
  7. 單步時間複雜度：$\mathcal{O}(1)$。
  8. 記憶體開銷：$\mathcal{O}(s)$（零 KV Cache 負擔！）。

3. 數值演算示範：序列長度 $L=65,536$ 時的訓練時間

  • S4 FFT 卷積運算量： $$L \log_2 L = 65536 \times 16 = 1,048,576 \quad (100 \text{ 萬次運算})$$

運算量級相差了 4000 倍！

4. 懸念與先猜後答

  2. S4 訓練時改用 FFT 卷積，把 1D 序列拉平成廣義向量乘法，讓 GPU 所有 CUDA 核心滿載轟炸！

🎓 大師教授口吻：「歡迎來到 2023–2024 年深度學習的最強明星——Mamba！如果說 S4 是硬梆梆的靜態過濾器，Mamba 就是擁有『智慧大腦』的自適應動態過濾器！」

1. 單一主線類比：死板的篩子 vs 智慧安檢門

  1. S4 (時不變 LTI)：像一個固定孔洞的死板篩子，不論掉下來的是黃金、沙子還是石頭，篩子孔洞的大小（矩陣 $A, B, C$）永遠不變。
  2. Mamba (選擇性 Selective)：像一個「智慧 AI 安檢門」！看到無關的沙子雜訊就自動關閉閥門（$\Delta_t \to 0$）；看到黃金關鍵資訊就瞬間打開大門（$\Delta_t \uparrow$），將其寫入記憶中！

2. 鷹架式拆解：Mamba 選擇性機制三大算式

Mamba 突破了 S4 的時不變性 (LTI) 限制，讓參數隨輸入 $\boldsymbol{x}_t$ 動態變化：

  1. 動態參數生成 (Content-Aware Parameterization)： $$\begin{align*} \boldsymbol{B}_t &= \text{Linear}_B(\boldsymbol{x}_t) \\ \boldsymbol{C}_t &= \text{Linear}_C(\boldsymbol{x}_t) \\ \Delta_t &= \text{Softplus}\left( \text{Parameter} + \text{Linear}_\Delta(\boldsymbol{x}_t) \right) \end{align*}$$
  2. 離散矩陣動態轉化： $$\overline{\boldsymbol{A}}_t = \exp(\Delta_t \boldsymbol{A}), \quad \overline{\boldsymbol{B}}_t = (\Delta_t \boldsymbol{A})^{-1} (\exp(\Delta_t \boldsymbol{A}) - \boldsymbol{I}) \cdot \Delta_t \boldsymbol{B}_t$$
  3. 動態門控狀態更新 (Hardware-Aware Scan)： $$\boldsymbol{h}_t = \mathbf{f}_{\text{gate}}(\boldsymbol{x}_t) \odot \left( \overline{\boldsymbol{A}}_t \boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}}_t \boldsymbol{x}_t \right), \quad \boldsymbol{y}_t = \boldsymbol{C}_t \boldsymbol{h}_t$$

3. 數值演算示範：選擇性動態開關行為

假設輸入 Token 為「關鍵實體名字」與「無關贅字」：

  • 當遇到關鍵 Token（如 "Albert Einstein"）：
  • $\text{Linear}_\Delta(\boldsymbol{x}_t)$ 輸出較大值 $\Rightarrow \Delta_t = 1.0$。
  • 狀態更新放行率高，資訊強行寫入隱藏狀態 $\boldsymbol{h}_t$！
  • 當遇到無關贅字 Token（如 "um... ah..."）：
  • $\text{Linear}_\Delta(\boldsymbol{x}_t)$ 輸出極小值 $\Rightarrow \Delta_t \to 0.001$。
  • $\overline{\boldsymbol{A}}_t \approx \boldsymbol{I}, \overline{\boldsymbol{B}}_t \approx 0 \Rightarrow \boldsymbol{h}_t \approx \boldsymbol{h}_{t-1}$。
  • 狀態完美跳過該 Token，保持舊記憶不受雜訊污染！

8. 一句話收尾口訣

「Mamba 突破時不變，動態參數隨內容；選擇過濾去雜訊，長文語言展神威。」

教授祕笈：測試時訓練 (TTT) 圖層：將隱藏狀態模型化為線上學習者

🎓 大師教授口吻：「如果說 Mamba 是給隱藏狀態裝上了『動態開關』，2024 年提出的 TTT 層則是做出了一個大膽的顛覆：把隱藏狀態直接升級為一個『會邊考邊學的微型神經網絡』！」

1. 單一主線類比：實習生邊做邊學

  1. 傳統 SSM（記憶體硬碟）：把讀到的資訊存在固定硬碟裡（矩陣乘法 $\overline{\boldsymbol{A}}\boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}}\boldsymbol{x}_t$）。
  2. TTT 層（動態學習實習生）：把隱藏狀態看作一個實習生 $\boldsymbol{\theta}_t$。每處理一個新 Token，實習生就做一次「自我測試與線上梯度下降更新（$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla \ell_t$）」，邊工作邊進化！

2. 鷹架式拆解：TTT 層三大步驟與算式

TTT 層將隱藏狀態轉化為線上自監督學習者：

  1. 隱藏模型前向預測： $$\hat{\boldsymbol{z}}_t = f_t(\boldsymbol{x}_t; \boldsymbol{\theta}_t)$$
  2. $\boldsymbol{\theta}_t$：時間步 $t$ 時隱藏微型模型（如 FNN）的權重。
  3. 自監督重建損失： $$\ell_t = \mathcal{L}\left( \hat{\boldsymbol{z}}_t, \tilde{\boldsymbol{x}}_t \right)$$
  4. $\tilde{\boldsymbol{x}}_t$：自監督目標（如受損輸入重建）。
  5. 線上測試時梯度更新 (Test-Time Training)： $$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla_{\boldsymbol{\theta}_t} \ell_t$$
  6. 權重 $\boldsymbol{\theta}_t$ 在推理階段隨著時間步 $t$ 持續被梯度推動更新！

3. 數值演算示範：單步均方誤差 (MSE) 梯度更新手算

假設微型模型為純量線性層 $f(x) = \theta x$，自監督目標為 $\tilde{x}$：

  1. 損失函數： $$\ell_t = \frac{1}{2} (\theta_t x_t - \tilde{x}_t)^2$$
  2. 計算梯度： $$\nabla_{\theta_t} \ell_t = (\theta_t x_t - \tilde{x}_t) x_t$$
  3. 權重更新： $$\theta_{t+1} = \theta_t - \eta (\theta_t x_t - \tilde{x}_t) x_t$$

設 $\theta_t = 2.0, x_t = 1.0, \tilde{x}_t = 1.0, \eta = 0.1$：

  • 誤差 $= 2.0 \times 1.0 - 1.0 = 1.0$
  • 梯度 $= 1.0 \times 1.0 = 1.0$
  • 新權重 $\theta_{t+1} = 2.0 - 0.1(1.0) = 1.90$（權重自動向正確目標修正！）。

2. 鷹架式拆解：線性注意力到 SSM 的五步證明

我們一步步拆解 Section 7 的證明：

  1. 線性注意力 (Linear Transformer)：
  2. 替換 Softmax 為核函數 $\phi(\boldsymbol{q}_t)^\top \phi(\boldsymbol{k}_i)$： $$\boldsymbol{y}_t = \frac{\sum_{i=1}^t \phi(\boldsymbol{q}_t)^\top \phi(\boldsymbol{k}_i) \boldsymbol{v}_i^\top}{\sum_{i=1}^t \phi(\boldsymbol{q}_t)^\top \phi(\boldsymbol{k}_i)}$$
  3. 因式分解提取 $\phi(\boldsymbol{q}_t)^\top$： $$\boldsymbol{y}_t = \frac{\phi(\boldsymbol{q}_t)^\top \sum_{i=1}^t \phi(\boldsymbol{k}_i) \boldsymbol{v}_i^\top}{\phi(\boldsymbol{q}_t)^\top \sum_{i=1}^t \phi(\boldsymbol{k}_i)}$$
  4. 定義矩陣狀態量 $\boldsymbol{H}_t$： $$\boldsymbol{H}_t := \sum_{i=1}^t \phi(\boldsymbol{k}_i) \boldsymbol{v}_i^\top \Rightarrow \boldsymbol{H}_t = \boldsymbol{H}_{t-1} + \phi(\boldsymbol{k}_t) \boldsymbol{v}_t^\top$$
  5. 採用線性核並去除分母歸一化：
  6. 取 $\phi(\boldsymbol{q}_t) = \boldsymbol{q}_t, \phi(\boldsymbol{k}_t) = \boldsymbol{k}_t$： $$\begin{align*} \boldsymbol{H}_t &= \boldsymbol{H}_{t-1} + \boldsymbol{k}_t \boldsymbol{v}_t^\top \\ \boldsymbol{y}_t &= \boldsymbol{q}_t^\top \boldsymbol{H}_t \end{align*}$$
  7. 結論（與 SSM 對齊）：
  8. 上式中 $\boldsymbol{H}_t = \boldsymbol{I} \boldsymbol{H}_{t-1} + \boldsymbol{k}_t \boldsymbol{v}_t^\top$ 精確對應於 SSM 的 $\boldsymbol{h}_t = \overline{\boldsymbol{A}}\boldsymbol{h}_{t-1} + \overline{\boldsymbol{B}}\boldsymbol{x}_t$（當 $\overline{\boldsymbol{A}}=\boldsymbol{I}$ 時）！
