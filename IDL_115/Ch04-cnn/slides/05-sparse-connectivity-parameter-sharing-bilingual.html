稀疏連線與參數共享 Sparse Connectivity and Parameter Sharing

全連線網路讓每一對輸入與輸出「人人握手」，參數量高達 $\mathcal{O}(m\times n)$。卷積神經網路藉由稀疏連線（每輸出僅看 $k$ 個鄰居）與參數共享（全圖共用同一組濾波器），將參數量陡降至 $\mathcal{O}(k\times n)$。這不是魔法，而是以空間局部性先驗換取的極致算力節省。

Fully connected layers wire every input to every output at O(m·n) cost. CNNs combine sparse connectivity (local receptive fields of size k) and parameter sharing (sweeping identical filters across the grid) to slash parameters to O(k·n).

01 / 核心提問 · Core Question
「每人一條專線 vs 同一把尺量全圖」 全連線讓每個位置獨立建立連線；卷積用一把小尺在全圖巡迴蓋印！
Dense wires everyone to everyone; CNN shares local rulers across space.
02 / 結構機制 · Sparse Connectivity

稀疏連線（Sparse Connectivity）：每個單元只看鄰居 Sparse Connectivity: Local Receptive Fields Instead of Global Dense Wiring

為什麼不需要「人人連線」？

在標準全連線網路中，若輸入有 $m$ 個畫素、輸出隱藏層有 $n$ 個神經元，權重矩陣包含 $m\times n$ 個獨立數值，每個輸出神經元都與 $m$ 個輸入相連。

然而自然影像具備強烈的局部統計相關性：左上角的一枚畫素只與其周圍相鄰畫素息息相關，而與右下角 200 畫素外的背景互不干擾。卷積層限制每個輸出單元僅連線至大小為 $k$（例如 $3\times 3=9$）的局部感受野（receptive field），切斷所有冗餘的遠端連線。

Nearby pixels are strongly correlated; distant ones are virtually independent. Receptive fields limit connections to size k.
03 / 權重復用 · Parameter Sharing

參數共享（Parameter Sharing）：全圖同一套權重 Parameter Sharing: Reusing Weights Across the Entire Spatial Grid

🚫 全連線層的權重孤立

Dense Layers: Single-Use Weights

全連線權重矩陣中的每一個元素 $w_{ij}$，一生只被使用一次——專門用來計算輸入第 $j$ 個節點與輸出第 $i$ 個節點的乘積。換了空間位置，就得重新學一套全新的獨立權重。

In dense layers, each weight is used exactly once for one specific pair of units.

♻️ 卷積層的極致復用

CNNs: Massive Weight Reuse

卷積核的 $k$ 個參數，在特徵圖的每一個空間位置都被重複使用！在左上角辨識水平邊緣的濾波器，滑動到右上角或中央時，仍然使用完全相同的這組權重。

In CNNs, the same kernel weights are reused at every spatial location across the entire image.
04 / 數學推導 · Complexity Analysis

參數量與計算量嚴格對比：$\mathcal{O}(mn)$ vs $\mathcal{O}(kn)$ Rigorous Parameter & Runtime Comparison: O(mn) vs O(kn)

數學對照表

設輸入空間節點數為 $m$、輸出節點數為 $n$、核尺寸為 $k$（且 $k \ll m$）：

  • 全連線層參數量：$\text{Params}_{\text{FC}} = m \times n = \mathcal{O}(mn)$
  • 卷積層參數量：$\text{Params}_{\text{Conv}} = k \times n = \mathcal{O}(kn)$
  • 壓縮比率：$\frac{\text{Params}_{\text{FC}}}{\text{Params}_{\text{Conv}}} = \frac{m \cdot n}{k \cdot n} = \frac{m}{k}$

例項：以 $224\times 224$ 彩色輸入為例，$m \approx 50,000$。若使用 $3\times 3$ 卷積核（$k=9$），理論壓縮比高達 $50,000 / 9 \approx 5,555$ 倍！

Compression ratio is strictly m/k. For high-resolution inputs, CNN saves several orders of magnitude in parameters.
05 / 視覺對比 · Visual Comparison

連線模式圖解：全連線義大利麵 vs 卷積局部蓋印 Visualizing Dense Wiring vs Convolutional Kernel Stamping

圖解稀疏連線與參數共享機制對比全連線

🔑 兩大機制缺一不可

  • 只稀疏、不共享：稱為 Locally Connected Layer（局部連線層）。每個局部位置依然擁有獨立權重，參數量仍遠高於卷積。
  • 只共享、不稀疏：如果核與全圖一樣大，那隻不過是拿一個巨大的全連線矩陣對全圖做一次性運算。
  • 稀疏 ＋ 共享：雙劍合璧，才成就了 CNN 的輕量與平移等變性！
Locally connected (sparse without sharing) still has high parameter count; sharing requires sparsity to be practical.
06 / 極限思考 · Boundary Case

極限思維：當 $k \to m$ 時的退化 Limiting Case: Degenerating to Fully Connected when k = m

💬 考題常客陷阱題

問：卷積層在什麼情況下會實質上退化為全連線層？
答：當卷積核尺寸 $k$ 等於輸入影像尺寸 $m$ 時。此時每個輸出單元都「看見」了全圖所有輸入，稀疏性歸零；又因為核尺寸與輸入相同，核無法在影像上滑動（只能蓋印一次），參數共享亦失去意義，數學形式與全連線矩陣完全一致。

When kernel size equals input size, the kernel covers the entire input without sliding. Sparsity and sharing both disappear, reducing to dense FC.
