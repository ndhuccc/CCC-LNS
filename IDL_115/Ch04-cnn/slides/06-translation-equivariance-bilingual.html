平移等價性（不是不變性） Translation Equivariance, Not Invariance

卷積運算對平移具備等價性（equivariance）：輸入平移，特徵圖以完全相同的幾何關係跟隨平移，即 $f(g(x)) = g(f(x))$。先平移再卷積與先卷積再平移結果完全相同。千萬別與池化提供的「平移不變性（invariance）」混為一談，更要注意：卷積對旋轉與尺度並不具備等價性！

Convolution is translation equivariant, not invariant: shifting input shifts the feature map identically: f(g(x)) = g(f(x)). Spatial location is preserved. Note that convolution does NOT guarantee equivariance to rotation or scaling.

01 / 核心提問 · Core Question
「平移等價：先平移再卷積 ＝ 先卷積再平移」 等價是「輸出跟著輸入走」（位置還在）；不變是「輸出數值完全不動」！
Equivariance moves with the input; invariance stays still. Convolution guarantees the former!
02 / 核心區分 · Fundamental Distinction

輸入挪一下，特徵圖也跟著挪——這叫等價，不是不變 When Input Moves, Features Move: That's Equivariance, Not Invariance

深度學習中最常被混淆的一組術語

請務必先把這兩個詞在腦中分開：

  • 等價性（Equivariance）：先變換再處理 $=$ 先處理再變換。輸入變換時，輸出以同樣的方式跟隨變換。輸出跟著動，相對空間座標被完整保住！
  • 不變性（Invariance）：輸入無論如何變換，輸出數值幾乎完全不動。

卷積是等價性，絕非不變性！如果一張照片裡的貓往右移動了 2 格，卷積特徵圖上的「貓特徵啟用區域」也必定往右移動 2 格。若卷積真是「不變」，特徵圖上的訊號就會完全待在原地，網路便再也無法分辨貓到底出現在畫面的左邊還是右邊！

If convolution were invariant, feature locations would not move, destroying spatial awareness of object coordinates.
03 / 數學形式化 · Mathematical Formulation

式 (5)：卷積與平移運算元的可交換性 Equation (5): Commutativity of Convolution and Translation Operators

形式化數學定義

若函式 $f(x)$ 與變換函式 $g(x)$ 滿足下式，則稱 $f$ 對 $g$ 具備等價性：

$$f(g(x)) = g(f(x)) \tag{5}$$

將 $g$ 視為平移操作（將影像位移 $\Delta$）、$f$ 視為卷積運算，式 (5) 表明下列兩條路徑殊途同歸：

  • 路徑 A（先移再卷）：$f(g(x))$ —— 先將輸入照片往右平移，再用卷積核掃描。
  • 路徑 B（先卷再移）：$g(f(x))$ —— 先對原照片做卷積，再將輸出的特徵圖往右平移。

為什麼兩路結果必定相同？答案正是上一節講的參數共享！同一顆核在全圖每個畫素位置都使用同一套權重，因此物體平移後，局部幾何紋理絲毫不變，濾波器在位移後的新座標自然會給出完全一模一樣的數值響應！

Parameter sharing guarantees that because the same kernel applies everywhere, moving the object yields identical outputs at shifted positions.

📐 為什麼旋轉和縮放不行？

  • 平移：只是座標原點改變，畫素網格之間的相對上下左右拓撲完全不變。
  • 旋轉：原本與「垂直邊緣核」對齊的直立線條，轉了 90° 變成水平線條，垂直核便再也偵測不到它！除非核本身是同心圓旋轉對稱的。
  • 縮放：特徵尺寸改變，超越了 3×3 核的感受野視窗。
Rotation changes relative orientation with respect to non-symmetric kernels; scale changes physical pixel footprint.
05 / 邊界範疇 · Limitations

實務工程啟示：旋轉與尺度如何獲得？ Engineering Implications: Achieving Rotation and Scale Robustness

🔄 資料增強（Data Augmentation）

Random Rotation & Scaling

在訓練時對輸入圖片施加隨機旋轉（RandomRotation）與隨機尺度縮放（RandomResizedCrop），強迫神經網路在多個特徵通道中自發學習不同方向的邊緣核。

Train with random rotations and crops so the network learns multi-orientation filter banks.

📐 專門架構模組（STN & Multi-Scale）

Spatial Transformer & FPN

使用空間變換網路（Spatial Transformer Networks, STN）自動學習幾何矯正常態化，或藉由特徵金字塔網路（FPN）在不同層級萃取多尺度特徵。

Use dedicated modules like STN for spatial rectification or Feature Pyramid Networks for multi-scale representation.

特性 Feature 平移等價性（Translation Equivariance） 平移不變性（Translation Invariance）
數學定義 f(g(x)) = g(f(x)) f(g(x)) = f(x)
輸出特徵行為 輸出特徵圖跟隨輸入同步位移 輸出數值保持靜止不動
主導模組 卷積層（Convolutional Layer） 池化層（Pooling Layer, 特別是 Global Pooling）
保留的資訊 物體的「在哪裡」（空間位置坐標） 物體的「是什麼」（語意類別存在性）
