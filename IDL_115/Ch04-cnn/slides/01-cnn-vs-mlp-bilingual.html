IDL 115 · CHAPTER 4 · KP-01 · TEACHING DECK

導論：CNN 對上 flatten-MLP Introduction: CNN vs Flatten-MLP

影像是二維空間結構資料；MLP 先 flatten 把鄰居關係摧毀，CNN 則直接在原始格子上滑動小濾波器，以稀疏連線與權重共享大幅降低參數量，同時帶來平移等變性這個重要的歸納偏置。

Images carry rich 2D spatial structure. Flattening for MLP destroys neighborhood relationships; CNN slides small filters across the original grid using sparse connectivity and weight sharing, dramatically reducing parameters while gaining translation equivariance as an inductive bias.

01 / 核心提問 · Core Question
「攤平一張照片，你能找到邊緣嗎？」 攤平（flatten）破壞空間結構——CNN 用局部濾波器把結構保住！
Flattening destroys spatial structure — CNN preserves it with local filters.
02 / 動機背景 · Image Structure

影像：高維 × 空間結構並存的資料 Images: High-Dimensional Data with Rich Spatial Structure

為什麼影像與向量不同？

一張 224×224 RGB 彩色照片展開後有 150,528 個畫素，但這些數字並非孤立的：

  • 局部相關性（Local Correlation）：相鄰畫素的顏色值非常接近，呈現平滑過渡。一隻貓的眼睛、耳朵、鼻子各自佔據連續的畫素區塊。
  • 二維結構（2D Structure）：「上下左右」的鄰居關係具有語義意義——水平邊緣在一行，垂直邊緣在一列，45° 斜線跨越對角線畫素。
  • 局部圖案重複出現（Local Patterns Repeat）：「邊緣」、「角落」、「紋理」等低階特徵在不同位置重複出現，不會因為位置不同就改變含義。
A 224×224 RGB image has 150,528 values, but they are spatially correlated: neighboring pixels share smooth color transitions, edges occupy contiguous rows/columns, and local patterns (edges, corners, textures) repeat across positions.
影像畫素的二維空間關係：局部相關、圖案重複、二維拓撲 · 2D spatial structure of image pixels

關鍵直覺

影像的高維度與空間結構是同時存在且深度耦合的。不能把高維當作純量處理、也不能忽視空間排列。

傳統機器學習處理表格資料（每列是獨立特徵），但影像畫素之間存在強烈的二維位置關係，這是影像專用架構誕生的根本動機。

Images combine high dimensionality with strong 2D spatial correlations. Traditional tabular-data models treat features as independent, which fundamentally mismatches image data.
03 / 缺陷分析 · MLP Flatten Problem

MLP 先 Flatten：摧毀二維鄰居關係 MLP Flatten: Destroying 2D Neighborhood Relationships

將 H×W 的影像先 flatten（攤平）成一條長向量再送入全連線 MLP，是一種看似簡單卻代價高昂的做法：二維空間結構被徹底摧毀。 Flattening an H×W image into a 1D vector before MLP processing seems straightforward but destroys all 2D spatial structure irreversibly.

✅ 原始二維排列

Original 2D Arrangement

畫素 (i,j) 的鄰居是 (i±1, j) 和 (i, j±1)，具有明確的空間距離與方向。

  • 「左邊」的畫素在水平方向相差 1 格
  • 「右下角」畫素比「左上角」遠很多
  • 相鄰畫素之間存在強相關
  • 水平/垂直方向的「邊緣」具有結構意義
Pixel (i,j) has neighbors at exact spatial distance 1; corner-to-corner pixels are far apart. Strong correlations exist only locally.

❌ Flatten 之後

After Flatten: Lost Forever

所有畫素被排成一列，左上角與右下角畫素成為「同等距離、同等相關」的鄰居。

  • 二維鄰居關係完全消失
  • 網路無法區分「相鄰」與「遙遠」的畫素
  • 學習「水平邊緣」需要同時記憶整行畫素的權重組合
  • 同一個「邊緣特徵」在不同位置需要獨立學習
All pixels become equidistant neighbors. The network cannot distinguish adjacent from distant pixels. Every edge detector must be re-learned at every position independently.

⚠️ 參數爆炸問題

設影像大小為 H×W = 28×28 = 784，第一層 MLP 使用 512 個隱藏單元： 第一層權重矩陣需要 784 × 512 = 401,408 個參數。 若換成 224×224 RGB 影像（150,528 維），單一層已需 ~77M 參數！

CNN 用 64 個 3×3 核心處理同一層：僅需 64 × 3 × 3 × 3 = 1,728 個參數，參數量下降 4400 倍以上。

A single MLP layer on 224×224 RGB input needs ~77M parameters; a CNN layer with 64 filters of 3×3 needs only 1,728. That's a 44,000× reduction.
04 / 核心原理 · CNN Principle

CNN：直接在二維格子上滑動濾波器 CNN: Sliding Filters Directly on the 2D Grid

CNN 的核心動作：卷積（Cross-Correlation）滑動

CNN 不 flatten 影像；它直接在原始的 H×W 格子上放置一個小小的濾波器（filter / kernel），讓這個濾波器從左到右、從上到下「滑」過整張影像。每滑到一個位置，就做一次內積運算，輸出一個數值到特徵圖（feature map）的對應位置。

CNN keeps the image 2D and slides a small filter (kernel) across it. At each position, it computes a dot product to produce one value in the output feature map.
CNN 卷積滑動：3×3 核心掃過 5×5 輸入，每個位置做內積，輸出 3×3 特徵圖 · Cross-correlation of 3×3 kernel on 5×5 input

卷積（Cross-Correlation）計算式

設輸入 $X$，核心（kernel）$W$ 大小為 $k \times k$，輸出特徵圖 $Y$ 的第 $(i,j)$ 格：

$$ Y[i,j] = \sum_{m=0}^{k-1}\sum_{n=0}^{k-1} X[i+m,\, j+n]\cdot W[m,n] + b $$

每個輸出位置都用同一組權重 $W$ 計算，這就是權重共享的數學形式。

Each output cell Y[i,j] is a dot product of the input patch with the same kernel W — this is exactly weight sharing.
05 / 結構改動 · Sparse + Shared

CNN = 全連線網路的特例：開啟兩個開關 CNN = Constrained Fully-Connected: Two Key Switches Flipped

從數學角度來看，CNN 可以視為標準全連線層（Fully-Connected Layer）的一種特例——只是在權重矩陣上施加了兩項嚴格限制，使得大部分權重被強制歸零或繫結相同值。 Mathematically, CNN is a restricted fully-connected layer: most weights are forced to zero (sparse connectivity) or shared across positions (weight sharing).

🔵 開關一：稀疏連線（Sparsity）

Sparse Connectivity / Local Receptive Field

全連線層中每個輸出單元連線所有輸入畫素；CNN 中每個輸出單元只連線一小塊（k×k）的輸入鄰居。

超出感受野範圍的輸入畫素，權重被強制設為 0——不連線、不影響、不學習。

Each output neuron connects to only a k×k local patch. All connections outside this receptive field are hard-zeroed.

🟡 開關二：權重共享（Weight Sharing）

Tied Weights / Parameter Sharing

全連線層中不同位置的連線使用獨立權重；CNN 要求所有位置共享同一組核心權重 $W$。

無論濾波器滑到左上角還是右下角，使用完全相同的 $W$——這就是「同一個探測器在全圖巡邏」。

All spatial positions share the exact same kernel weights W. The same pattern detector patrols the entire image.

📐 兩者的聯合效果

Combined Effect

假設輸入 28×28，全連線層接 512 個神經元：
全連線：$784 \times 512 = \mathbf{401,408}$ 參數
CNN（64 個 3×3 核心）：$64 \times 9 = \mathbf{576}$ 參數

FC: 401,408 parameters → CNN: 576 parameters. Nearly 700× reduction on 28×28 input.

🧠 歸納偏置的本質

Inductive Bias Built In

稀疏 + 共享編碼了一個強烈的先驗假設：「局部圖案到處都可能出現，且意義相同」。這個先驗對自然影像高度成立，大幅減少所需的訓練樣本數。

Sparse + shared encodes the prior: "local patterns can appear anywhere with the same meaning" — a strong inductive bias for natural images.

06 / 三大好處 · Three Benefits

稀疏連線 + 權重共享帶來的三大好處 Three Key Benefits of Sparse Connectivity + Weight Sharing

🔢 好處一：參數量大幅下降

Benefit 1: Massive Parameter Reduction

稀疏連線（每神經元只看 k×k 鄰居）與權重共享（全圖同一組權重）雙管齊下，使參數量從 $O(HW \cdot d_{in} \cdot d_{out})$ 降至 $O(k^2 \cdot C_{in} \cdot C_{out})$。

參數量的驟降意味著更少的 overfitting 風險、更少的記憶體消耗、更快的訓練速度。

Parameters scale as O(k² · C_in · C_out) instead of O(H·W·d_in·d_out) — orders of magnitude fewer. Less overfitting, faster training.

🎯 好處二：內建先驗假設

Benefit 2: Built-In Inductive Prior

權重共享對應一個強烈的歸納偏置（inductive bias）：「同一個局部圖案在影像的任意位置出現時，都應被同等強度地偵測到」。

這個先驗對於自然影像（貓的耳朵可以出現在任何位置）幾乎總是成立，大幅減少有效訓練所需的樣本數量。

The inductive bias "any local pattern should be detectable everywhere" matches natural image statistics perfectly, greatly reducing sample complexity.

↔️ 好處三：平移等變性

Benefit 3: Translation Equivariance

若輸入影像平移 $(\Delta x, \Delta y)$，則 CNN 輸出的特徵圖也跟著平移相同的量——這是數學上可嚴格證明的性質。

注意：這是「跟著走」（equivariance），不是「不變」（invariance）。平移不變性（translation invariance）要等到池化層之後才出現。

If input shifts by (Δx, Δy), the feature map shifts by the same amount. This is equivariance — not invariance (which requires pooling).

📊 三大好處彙總

Summary
  • 參數量 $\downarrow$（從億級到千級）
  • 歸納偏置 = 局部特徵圖案到處都有
  • 平移等變性 = 特徵圖跟著輸入走

三者共同讓 CNN 成為處理影像的標準首選架構。

These three properties collectively make CNN the default architecture for image processing.
07 / 深入理解 · Translation Equivariance

平移等變性 vs 平移不變性：兩者的精確區別 Translation Equivariance vs Translation Invariance: The Precise Distinction

精確數學定義

設 $T_{\Delta}$ 為平移運算元（將影像平移 $\Delta$ 的運算），$f$ 為 CNN 的卷積運算：

平移等變性（Equivariance）： $f(T_{\Delta}(x)) = T_{\Delta}(f(x))$

平移不變性（Invariance）： $f(T_{\Delta}(x)) = f(x)$（加了池化之後才成立）

Equivariance: f(T(x)) = T(f(x)) — output shifts with input. Invariance: f(T(x)) = f(x) — output unchanged despite input shift (requires pooling).

↔️ 平移等變性（CNN 卷積層）

Translation Equivariance — CNN Conv Layer
  • 貓的耳朵從左上移到右下 → 特徵圖中「耳朵」的響應也跟著移到右下
  • 「特徵位置」在特徵圖中忠實反映輸入中物體的位置
  • 這讓深層網路能夠基於特徵位置做進一步的空間推理
  • 卷積層本身保留了位置資訊
If the cat's ear moves in the input image, the "ear feature" in the feature map moves by the same amount. Spatial location is preserved.

🔒 平移不變性（池化層之後）

Translation Invariance — After Pooling
  • 貓的耳朵從左上移到右下 → 輸出不變
  • 池化（MaxPool、AvgPool）對局部區域取聚合，丟棄精確位置
  • 使分類結果不受物體精確位置影響
  • 代價：位置資訊被丟失（對 Detection、Segmentation 不利）
After pooling, the output is unchanged despite input shifts. Position information is discarded — good for classification, bad for detection/segmentation.

✅ 口訣記憶

「等變 = 跟著走，不變 = 看不出來」
卷積層：貓在左，特徵在左；貓在右，特徵在右。→ 等變
池化後：不管貓在哪裡，分類結果都一樣。→ 不變

Equivariance = output "follows" input translation. Invariance = output is "oblivious" to input translation.

09 / 口語總結 · Summary

口語小結：CNN vs MLP Flatten 核心對比 Summary: CNN vs MLP Flatten — The Core Contrast

💬 一段話版總結

MLP 先 flatten 等於把空間關係丟掉——左上角和右下角畫素變成一樣近，網路學不會「局部」是什麼。CNN 用稀疏連線讓每個輸出只看一小塊鄰居，再加上權重共享讓同一組權重掃全圖，既省參數又自帶「局部圖案到處都有」的先驗，還順帶獲得平移等變性——輸入往哪移，特徵圖就往哪移。這一切都來自兩個開關：稀疏連線 + 權重共享。

MLP flatten discards spatial relationships. CNN uses sparse connectivity (local receptive field) + weight sharing (same kernel everywhere) to preserve 2D structure, reduce parameters by orders of magnitude, build in the "local patterns repeat" prior, and achieve translation equivariance — all from just two structural constraints.

MLP Flatten 關鍵詞

  • H×W → 一維長向量
  • 二維鄰居關係消失
  • 參數量 $O(HW \cdot d)$
  • 無內建空間先驗
  • 學「邊緣」需要記整行權重

CNN 關鍵詞

  • 保持 H×W 二維結構
  • 稀疏連線（k×k 局部感受野）
  • 權重共享（同一核心全圖滑動）
  • 參數量 $O(k^2 \cdot C)$
  • 平移等變性內建
