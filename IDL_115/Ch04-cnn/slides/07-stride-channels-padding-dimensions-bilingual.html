步幅、通道、填充與輸出尺寸 Stride, Channels, Padding, and Output Dimensions

卷積運算的幾何輸出完全由四個超參數旋鈕決定：Stride（步幅）、Width（核寬）、Channels（通道深度） 與 Padding（填充邊界）。透過經典幾何公式 $\lfloor(d-f+2p)/s+1\rfloor$，精確預測每一層特徵圖的空間解析度，並釐清核深度與輸出特徵圖張數的本質差異。

Spatial output size is governed by four knobs: stride, kernel width, channels, and padding. The universal formula floor((d - f + 2p)/s) + 1 accurately predicts spatial resolution across complex architectures.

01 / 核心提問 · Core Question
「不補邊輸出會縮一圈；padding 把那圈補回來！」 核中心對不到最外圈畫素，valid 必然縮邊；邊界尺寸公式精確掌管空間解析度。
Unpadded convolution shrinks the feature map; padding restores spatial dimensions.
02 / 核心超參數 · Four Knobs

四大控制旋鈕：stride、width、channels、padding The Four Primary Control Knobs of Convolution

👣 1. Stride（步幅）

Step Size of Kernel Traversal

濾波器在空間網格上滑動時每次移動的格數。$s=1$ 為逐畫素連續平移；$s=2$ 每次跳躍 2 格，相當於在卷積階段直接進行下取樣，輸出尺寸大致折半。

Stride determines spatial step size. Stride > 1 aggressively downsizes the feature map.

📏 2. Width（核寬 / 空間尺寸）

Kernel Spatial Dimension (f × f)

濾波核的長寬尺寸 $f$（現代多為 $3\times 3$ 或 $5\times 5$）。小核專注微觀細節，大核一次涵蓋更寬廣的局部上下文。

Spatial extent f. Modern CNNs favor small stacked 3×3 kernels over large ones.

🥞 3. Channels（通道深度）

Kernel Depth vs Output Maps

關鍵澄清：一顆濾波核的「深度」必須嚴格對齊輸入通道數 $C_{in}$！而「輸出特徵圖張數 $C_{out}$」則是由有幾顆獨立的濾波核所決定。兩者絕對不能混淆！

A single kernel's depth equals C_in. The number of output maps equals the number of distinct kernels C_out.

🧱 4. Padding（邊界填充）

Border Value Injection

在輸入影像外圍擴充邊界畫素圈數 $p$。完全不補邊稱為 valid padding（$p=0$）；維持輸入與輸出長寬相同的設定稱為 same padding。

Padding controls border behavior and prevents boundary information loss.
03 / 數學定理 · Output Dimension Formula

式 (6)：輸出特徵圖空間尺寸精確定理 Equation (6): Spatial Output Dimension Formulation

尺寸公式式 (6)

設輸入長寬為 $d$、卷積核寬為 $f$、單側填充為 $p$、步幅為 $s$。輸出特徵圖的空間尺寸嚴格由下式決定：

$$\text{Output Dimensions} = \left\lfloor\frac{d - f + 2p}{s} + 1\right\rfloor \times \left\lfloor\frac{d - f + 2p}{s} + 1\right\rfloor \tag{6}$$

其中 $\lfloor\cdot\rfloor$ 代表無條件向下取整（Floor 運算）。

  • 有效覆蓋跨度：$d + 2p - f$ 為濾波核可在輸入邊界內滑動的最大淨位移。
  • 段數計算：除以步幅 $s$ 後取整，再加上初始出發的第 1 格，即得輸出邊長。

算例 1 (Valid)：$d=5, f=3, p=0, s=1 \implies \lfloor(5-3+0)/1 + 1\rfloor = 3$（$5\times 5 \to 3\times 3$，外圈被削掉一圈）。
算例 2 (Same)：$d=5, f=3, p=1, s=1 \implies \lfloor(5-3+2)/1 + 1\rfloor = 5$（$5\times 5 \to 5\times 5$，尺寸完美保全）。

Floor((d - f + 2p)/s) + 1 accurately determines width and height independently for any convolution setup.
04 / 填充策略 · Padding Strategies

課本列出的五種主要填充策略 Five Principal Padding Methods Described in the Textbook

填充方法 Method 邊界數值來源 Implementation 典型適用場景 Typical Usage
Zero Padding 在周圍均勻補上數值 0（最普遍） 標準深度學習架構（ResNet、VGG 等預設值）
Constant Padding 在周圍補上使用者指定的固定常數 $c$ 有特定背景基準值（如平均亮度）的影像任務
Replicate Padding 直接複製並向外延伸最邊緣一排的畫素值 邊緣紋理連續性要求高的影像修復或分割
Reflect Padding 沿著影像邊界做映象對稱翻折複製 風格遷移（Style Transfer）、超解析度（Super-Resolution）
Circular Padding 將影像頭尾相接、左右迴圈週期性環繞 全景圖（360° Panorama）、週期性晶格物理模擬
05 / 多通道張量 · Multichannel Tensors

課本 Fig. 5 與 Fig. 6：從單通道平面到三維張量 From 2D Single-Channel to 3D Multichannel Tensor Convolutions

立體張量卷積的正確心智模型

  • 單通道卷積（Fig. 5）：$1 \text{ 個平面輸入} \times 1 \text{ 個 2D 核} \implies 1 \text{ 張輸出特徵圖}$。
  • 多通道卷積（Fig. 6）：輸入有 3 個色彩通道（RGB）。此時每一顆濾波核本身就是一個 3D 張量（尺寸為 $f \times f \times 3$）！ 它在 3 個通道上分別做 2D 乘加，並在通道維度求和，輸出依然是單張 2D 特徵圖。
  • 產生多張特徵圖：如果你希望下一層擁有 16 個特徵通道，你必須準備 16 顆互不相干的 3D 濾波核！ 總參數量即為：$f \times f \times C_{in} \times C_{out}$（加上 $C_{out}$ 個偏置項）。
A filter is a 3D tensor of shape f×f×C_in. To produce C_out output maps, we use C_out distinct 3D filters.
06 / 尺寸對比 · Visualizing Output Sizes

不補邊（Valid）vs 補一圈（Same）視覺對照圖 Visual Comparison: Valid (p=0, Shrinking) vs Same (p=1, Preserving)

圖解 Valid Padding 與 Same Padding 空間尺寸演化對比

💡 Valid 不是「比較正確」

英文名詞「Valid」常被誤解為「合法的／正確的」。實際上，在訊號處理歷史中，Valid 只是指「完全不擴充邊界、只在純淨原訊號內部運算」。

在現代數十層乃至上百層的深層神經網路中，若每一層都用 Valid，特徵圖長寬會迅速縮減為 0。因此現代架構（如 ResNet）幾乎全數採用 $3\times 3$ 搭配 $p=1$ 的 Same Padding 保持空間尺寸！

Valid simply means no padding. Deep CNNs heavily rely on Same padding (f=3, p=1) to prevent rapid spatial collapse.
