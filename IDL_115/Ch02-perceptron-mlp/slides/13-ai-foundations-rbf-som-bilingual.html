兩種「偷懶」思路 Two clever shortcuts

RBF 與 SOM 都不是現在深度學習的主線，卻把「區域性感應」與「自組織拓撲」這兩種重要想法講得很清楚。Both models sit beside today’s deep-learning mainstream, but expose two durable ideas: locality and topology.

RBF：看準地方再插旗 Place local flags

它是監督式學習：有輸入，也有標準答案。第一層先在資料空間放置中心與感應範圍，第二層再學如何加權組合這些區域性訊號。Supervised learning: fixed local responses first, trainable output weights second.

監督式 · Supervised區域性基函式 · Local basis

SOM：自己找同類湊一坨 Organize by similarity

它是無監督式學習：沒有標準答案。每次找出最像輸入的勝者，再讓鄰居一起學，逐步形成有順序的 1D 或 2D 地圖。Unsupervised learning: a winner and its neighbors learn together to form an ordered map.

無監督式 · Unsupervised拓撲保序 · Topology-preserving

先記住一句話 · One-line memory

RBF 把「距離」變成區域性響應；SOM 把「相似性」變成格子上的鄰近關係。RBF turns distance into local response; SOM turns similarity into neighborhood.

RBF：兩層，把區域性訊號接起來 Two layers of local response

RBF 先算「離哪一面旗子近」，再把區域性回應加權合成預測。 · Local responses are weighted into a prediction.

第一層：固定基函式 · Fixed basis functions

RBF 的「偷懶」之處：不要求第一層反覆學所有權重，而是在資料空間選中心 $\mu_j$，用 $\sigma_j$ 決定感應範圍。The first layer places centers and widths to detect local regions.

第二層：可訓練權重 · Trainable weights

輸入透過每個高斯旗子後，得到一組區域性回應 $\phi_j(x)$；第二層學習 $W$，把它們加權組合成輸出。The second layer combines local responses with trainable weights.

RBF 核心計算 · Core equations

$$\phi_j(x)=\exp\left(-\frac{\lVert x-\mu_j\rVert^2}{2\sigma_j^2}\right),\qquad \hat y=\sum_{j=1}^{M}w_j\phi_j(x)$$

距離越近，$\phi_j(x)$ 越大；距離很遠時，回應快速趨近於 0。Nearer centers respond more strongly; faraway centers fade toward zero.

數值示例：一面高斯旗子怎麼預測？ One Gaussian flag, one prediction

把抽象的「區域性感應」化成三步：量距離、算回應、乘上權重。Turn locality into three moves: measure distance, compute response, apply the weight.

已知條件 · Given

$\mu_1=3,\ \sigma_1=1,\ w_{11}=2,\ x=4$。Center 3, width 1, output weight 2, input 4.

1

量距離 · Distance

$(x-\mu_1)^2=(4-3)^2=1$。Squared distance equals 1.

2

算高斯回應 · Response

$1/(2\sigma_1^2)=1/2=0.5$，所以 $\phi_1(4)=e^{-0.5}\approx0.606$。The nearby flag responds about 0.606.

3

加權輸出 · Weight

$\hat y=w_{11}\phi_1(4)=2\times0.606=\mathbf{1.212}$。The weighted prediction is 1.212.

直覺：$x=4$ 離中心 $3$ 很近，所以旗子有感應。 ŷ = 1.212 Intuition: the input is close to the center, so the local detector is active.

最小二乘：數學家的「一步到位」 Closed-form least squares

把所有區域性回應堆成 Φ，再直接求出最佳 W。 · Stack local responses into Φ, then solve for W.

三個動作 · Three moves

  1. 把全部基函式輸出寫成矩陣 $\Phi$。Collect basis responses in Φ.
  2. 把正確答案整理成 $Y$。Collect target outputs in Y.
  3. 讓 $W^\top\Phi$ 與 $Y$ 的誤差範數最小。Minimize the residual norm.

矩陣太奇怪？ · Singular case

若 $\Phi\Phi^\top$ 是奇異矩陣，不能直接取逆；改用偽逆 $\Phi^+$，仍能得到一個穩健解。If the matrix is singular, use the pseudo-inverse.

閉式解與偽逆 · Closed form and pseudo-inverse

$$W=(\Phi\Phi^\top)^{-1}\Phi Y^\top,\qquad W=\Phi^{+}Y^\top\ \text{when a pseudo-inverse is needed}$$

這裡的「偷懶」不是不學，而是把可用的線性代數一次算完，不必反覆梯度疊代。The shortcut is algebraic: solve the available linear problem directly instead of iterating.

SOM：沒有答案，也能長出一張地圖 A map without labels

SOM 將相似輸入安排在格子上相近的位置。 · Similar inputs activate nearby map neurons.

1982 · Kohonen 的想法 Kohonen, 1982

SOM 是單層網路，把神經元排成 1D 或 2D 格子；沒有標籤，也不預先指定簇。A single-layer 1D or 2D lattice organizes data without labels or preset clusters.

拓撲保序 · Topology preservation

相似的輸入不只要分到相同區域，還應該落在地圖上相鄰的位置；這就是「鄰居一起學」的理由。Similar inputs should remain neighbors on the map.

SOM 五步：神經元的選秀大賽 The five-step training loop

先看兩個核心公式 · Two core equations

$$z=\arg\min_j\lVert x-w_j\rVert,\qquad w_j(t+1)=w_j(t)+\eta(t)h_{zj}(t)\bigl(x-w_j(t)\bigr)$$

$z$ 是最接近輸入的 BMU；$h_{zj}(t)$ 決定第 $j$ 個神經元受鄰域影響的強度。z is the best matching unit; h controls neighborhood influence.

1

初始化 · Initialize

所有神經元權重先設成小隨機值。Start with small random weight vectors.

2

挑輸入 · Sample

選一筆輸入 $x$，讓整張地圖開始比對。Present one input vector x.

3

找勝者 · BMU

距離最近的神經元成為勝者 $z$。The nearest neuron becomes the BMU.

4

鄰域更新 · Update

勝者與 $N_z$ 內的鄰居一起向 $x$ 移動。The BMU and its neighbors move toward x.

5

衰減迭代 · Decay

$\eta(t)$ 與鄰域半徑逐步縮小，直到收斂。Learning rate and radius decay toward convergence.

訓練後 · After training

相似資料會被對映到格子上的相鄰神經元；測試時只要找 BMU，就能知道它落在哪個簇。After training, nearby map units reveal clusters; testing only requires finding the BMU.
