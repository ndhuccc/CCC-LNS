Perceptron 的三大支柱 Three Pillars of the Perceptron

現代模型再複雜，也仍能在這裡看到「輸入如何被加總、輸出如何做決策、錯誤如何改設定值」的骨架。 Complex models still echo weighted inputs, decisions, and parameter updates.

Σ

加權輸入 Weighted input

每個特徵乘上權重，表示它在目前決策中的影響力。 Weights encode feature influence.

±

啟用函式 Activation

把連續的總分轉成類別符號，決定輸出哪一側。 An activation turns a score into a class sign.

↻

權重更新 Weight update

預測錯誤時，沿著標籤指向修正設定值；猜對則保持不動。 Mistakes move parameters; correct cases stay still.

牛肉麵比喻 · Noodle-shop Analogy

牛肉入不入味與冷氣涼不涼可以有不同權重；模型不是「有感覺」，只是把重要性寫進乘法。 Different features get different numerical influence.

S2 · 維持注意

從格子派到正負號派 Binary Step vs. Signum

二元步階使用 $\{0,1\}$；Signum 改用 $\{+1,-1\}$，讓「方向」直接留在標籤裡。 Binary Step uses $\{0,1\}$; Signum keeps class direction as $\{+1,-1\}$.

二元步階 · Binary Step

$$\hat{y}=\begin{cases}1,&z\ge 0\\0,&z\lt 0\end{cases}$$

輸出像分班格子：不是 1，就是 0。 A crisp two-bin decision.

  • 適合二元開關 A binary switch.
  • 誤差差值不會固定成同一個量級 The error gap is less symmetric.

符號函式 · Signum

$$o_i=\operatorname{sign}(z_i)=\begin{cases}+1,&z_i\gt 0\\-1,&z_i\lt 0\end{cases}$$

等於零的邊界案例先略過，重點放在兩側方向。 Ignore the zero edge case and focus on direction.

  • 正類是 $+1$，負類是 $-1$ Positive is $+1$; negative is $-1$.
  • 猜錯時差值必為 $\pm 2$ A mistake always creates $\pm 2$.

編碼的效果 · Why the recoding helps

這不是改變資料的真實意義，而是換一種對更新規則更友善的表示法。 The labels change representation, not meaning.

S2 · 維持注意

四種組合，其實只剩兩種結果 Four Combinations, Two Outcomes

在 $\{+1,-1\}$ 的世界裡，先把 $y_i-o_i$ 寫出來，更新規則就不再像黑箱。 Expand $y_i-o_i$ and the update rule becomes transparent.

1

$+1$ 猜 $+1$

$y_i-o_i=+1-(+1)=0$ Correct: zero error.

2

$-1$ 猜 $-1$

$y_i-o_i=-1-(-1)=0$ Correct: zero error.

3

$+1$ 猜 $-1$

$y_i-o_i=+1-(-1)=+2$ Wrong: positive correction.

4

$-1$ 猜 $+1$

$y_i-o_i=-1-(+1)=-2$ Wrong: negative correction.

誤差的壓縮結論 · Compressed Error

$$y_i-o_i\in\{0,+2,-2\}$$

猜對是 0；猜錯只有 $\pm 2$，因此修正方向由 $y_i$ 決定。 Correct means zero; wrong means a signed step of magnitude two.

S2 · 維持注意

把差值推成更新 From Error Difference to Update

一般規則 · General rule

$$w\leftarrow w+\eta(y_i-o_i)x_i$$

這條式子把誤差乘上特徵，形成設定值修正量。 Error times input becomes the parameter correction.

只看猜錯案例 · Misclassified case

$$o_i\ne y_i\Longrightarrow y_i-o_i=2y_i$$

因此可改寫為： For a mistake, the rule simplifies to:

$$w\leftarrow w+2\eta y_i x_i$$

偏置也一起更新 · Bias update

若把偏置視為常數特徵 $1$，它同樣沿著錯誤方向修正。 Treating bias as a constant feature gives the same logic.

$$w_0\leftarrow w_0+2\eta y_i$$

名詞辨識 · Name the loss correctly

這裡的 $y_i-o_i$ 是感知機的預測誤差，不是 Lasso 的罰金；Lasso 是另一種正則化方法。 This is perceptron error, not a Lasso penalty.

批次版本 · Batch form

$$w\leftarrow w+2\eta\sum_{i\in\mathcal{M}}y_i x_i,\qquad w_0\leftarrow w_0+2\eta\sum_{i\in\mathcal{M}}y_i$$

$\mathcal{M}$ 表示目前被分錯的樣本集合；只累加需要修正的資料。 Sum only over the misclassified set $\mathcal{M}$.

手算一：猜錯了 Worked Example 1 — Wrong Prediction

把「讀書時數」當成唯一特徵：$x_i=10$，真實標籤是 $y_i=-1$（不及格）。 One feature: ten study hours, but the true class is $-1$.

欄位 · Item設定／計算 · Setting / Calculation結果 · Result
初始設定 · Initial$w=0.5,\;w_0=0,\;\eta=0.1$準備推論 · Ready
總分 · Score$z=0.5\times10+0$$z=5$
Signum$o_i=\operatorname{sign}(5)$$+1$，猜錯 · Wrong
更新 · Update$y_i-o_i=-1-(+1)=-2$$w=-1.5,\;w_0=-0.2$
1

先算總分

$z=5\gt 0$，所以輸出 $+1$。 A positive score predicts $+1$.

2

抓到錯誤

$y_i-o_i=-2$，修正方向朝負類。 The error points toward class $-1$.

3

更新權重

$w\leftarrow0.5+0.1(-2)(10)=-1.5$。 The weight crosses below zero.

4

更新偏置

$w_0\leftarrow0+0.1(-2)=-0.2$。 The bias becomes more negative.

讀懂結果 · Read the result

模型不是被「狠狠修理」，而是依照可追蹤的乘法把錯誤放大到輸入尺度，再改變下一次決策。 The correction is traceable: error scaled by the input changes the next decision.

手算二：猜對了 Worked Example 2 — Correct Prediction

換一筆資料：$x_i=1$、$y_i=-1$，並沿用剛剛更新後的 $w=-1.5$ 與 $w_0=-0.2$。 Reuse the updated parameters on a new negative example.

總分與輸出 · Score and output

$$z=(-1.5)(1)+(-0.2)=-1.7$$ $$o_i=\operatorname{sign}(-1.7)=-1$$

真實標籤也是 $-1$，因此 $o_i=y_i$。 The prediction matches the true label.

不需要更新 · No update needed

$$y_i-o_i=-1-(-1)=0$$

所以 $w$ 與 $w_0$ 保持原值；猜對就原地不動。 Correct predictions leave the parameters unchanged.

對照前一例 · Compare with Example 1

猜錯帶來有方向的修正；猜對把修正量消成 0。 Mistakes move; correct cases stay still.

一句話 · One sentence

Perceptron 的學習不是每筆資料都改，而是僅在預測與標籤不一致時改。 Learning happens only when prediction and label disagree.

Perceptron 是幾何雕刻家嗎？ Decision Boundary and Normal Vector

它確實在特徵平面上畫出邊界，但單一 Perceptron 畫的是直線；真正的超能力是用權重決定方向。 A single perceptron draws a linear boundary; weights set its orientation.

虛線是決策邊界；品紅箭頭是法向量，永遠垂直於邊界 · Boundary and normal.

核心公式 · Core equation

$$s(\mathbf{x})=w_1x_1+w_2x_2+b=\mathbf{w}^{\top}\mathbf{x}+b$$

當 $s(\mathbf{x})=0$ 時得到決策邊界；正負號分別位於邊界兩側。 The sign of the score selects a side of the boundary.

法向量的工作 · What the normal does

$\mathbf{w}=[w_1,w_2]$ 決定邊界的垂直方向；改變權重就會旋轉這條線。 Weights orient the perpendicular direction.

重要修正 · Important correction

單一 Perceptron 本身只能做線性切割；「非線性切割」需要特徵轉換或多層網路，不是這一條直線自己完成。 Nonlinear separation needs transformed features or multiple layers.

投影分數：把二維資料壓成一條軸 Projection Score: 2D to 1D

選擇 $\mathbf{w}=[1,1]$ 時，先看原始投影 $p(\mathbf{x})=\mathbf{w}^{\top}\mathbf{x}$；再加上偏置得到決策分數 $s(\mathbf{x})=p(\mathbf{x})+b$。 Project first, then shift the score with the bias.

十個樣本的實算 · Ten Samples, Real Computation

-10.5

資料點 A 的原始投影為 5，資料點 B 的原始投影為 16；滑動偏置，觀察整條分數軸如何平移。 Class A projects to 5; class B projects to 16. Bias shifts every score.

類間與類內 · Between and within classes

本例讓同類樣本的原始投影集中在 5 或 16，清楚展示「投影後的分數軸」；這是觀察工具，不代表 Perceptron 自動完成降維學習。 The projection is an analysis lens, not automatic dimensionality reduction.

由分數回到分類 · From score to class

以 0 為決策基準時，$s(\mathbf{x})\gt 0$ 輸出 $+1$，$s(\mathbf{x})\lt 0$ 輸出 $-1$。 The sign of the shifted score gives the class.
