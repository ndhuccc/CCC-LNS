PATTERN RECOGNITION · PR115 · LESSON 00

圖形識別
Pattern Recognition

第一堂課：課程說明與修課規定
Orientation — Course Overview & Policies
你的手機，怎麼一眼就認出那是你？ How does your phone recognize your face in an instant?

開場 · Opening

解鎖手機的人臉辨識、串流平台的影片推薦、醫院裡的影像判讀、工廠產線的瑕疵檢測—— 這些看似不相關的技術，其實都在解同一道題：「如何讓機器從資料中辨認出模式（pattern）」。 這門課，就是要帶你從頭建立這套思考方式。 Face unlock, video recommendation, medical imaging, defect inspection — all solve one core question: how machines recognize patterns in data.

S1 · 引起動機

學完之後，你能做什麼 What You'll Be Able to Build

生物特徵辨識

Biometric Recognition

人臉解鎖、指紋比對、虹膜辨識背後的分類器設計。(classifiers behind face/fingerprint unlock)

醫學影像診斷

Medical Imaging Diagnosis

從 X 光、MRI 影像中自動標記可疑病灶區域。(flagging suspicious regions in X-ray/MRI)

語音與文字助理

Speech & NLP Assistants

語音指令辨識、垃圾郵件過濾、情感分析的統計基礎。(statistical basis for speech/spam/sentiment)

異常與瑕疵偵測

Anomaly & Defect Detection

工業產線、金融交易中「找出不正常」的模式辨識任務。(finding the abnormal in production/finance)

直覺理解 · Intuition

這些應用的共通核心，都是「特徵擷取 + 決策規則」：先把原始資料（像素、聲波、數值）轉成有意義的特徵， 再用一套規則（分類器）做出判斷。這門課會系統性地教你如何設計這兩個環節。 All share one core: feature extraction + decision rule. This course teaches you both systematically.

修課規定 Course Policies

課堂參與 · Participation

每次上課會有隨堂測驗，目的是確保進度跟上、不要留到期末才複習。 鼓勵課堂提問與討論，也歡迎下課後用課程群組非同步提問。 In-class quizzes each session keep pace; ask questions freely, in class or via the course chat.

學術誠信與 AI 工具使用 · Academic Integrity & AI Use

這門課「鼓勵」使用 AI 工具（如 Claude Code、Copilot）輔助學習與實作，但前提是「使用透明、理解到位」。 考試與個人作業需獨立完成；期末專案雖然要求善用智能體協作，但必須完整記錄提示詞與判斷過程（見後段說明）， 不可只是複製貼上而不理解產出內容。抄襲他組成果或隱匿 AI 使用方式，視同違反學術誠信。 AI tools are encouraged if used transparently; copying without understanding, or hiding AI usage, counts as an integrity violation.

期末專案：AI 協作實戰 Final Project — AI-Assisted Collaboration

期末專案六階段流程 · Six-stage Project Pipeline

這是什麼 · What Is This

期末專案採分組進行，明確要求「善用智能體」協助實作——這不是選項，而是規定。 你們要學會如何指揮 AI 完成任務，而不是自己埋頭手刻每一行程式碼。 Using AI agents to implement your project is required, not optional — learn to direct AI, not hand-code everything.

為什麼這樣設計 · Why It Matters

業界現在最需要的能力，正是「與 AI 協作解決真實問題」的能力。 這個專案設計，就是要讓你提前練習這件事，並留下可驗證的過程紀錄。 Working with AI to solve real problems is now a core industry skill — this project lets you practice it, with a verifiable trail.

今天下課前 · Before We End Today

還不會 Git、也沒用過 AI 智能體？沒關係——今天下課前老師會現場示範一次完整流程： 用 AI agent 做出一個小小的分類器、用 Git 記錄修改過程、最後示範怎麼填寫 PROMPTS.md。 No Git or AI-agent experience needed — a full live demo (build, commit, log prompts) closes today's class.

S2 · 維持注意

期末專案規則細節 Project Requirements in Detail

Git 版本控管要求 · Git Requirements

每組建立 GitHub repo，全程使用 Git 進行版本控管：需有足量、有意義的 commit 紀錄， 不可在截止前一次性上傳交差。README 需說明專案目標、如何執行、系統架構。 Meaningful, frequent commits required — no single last-minute upload; README must explain goal, usage, architecture.

AI 使用紀錄要求 · Prompt Log Requirements

Repo 內必須包含 PROMPTS.md（或 prompts/ 資料夾），記錄使用了哪些 AI 智能體、 關鍵提示詞與對應的產出／commit，以及你們自己如何檢查與修改 AI 產出的內容。 課程提供固定範本，直接複製使用即可，不用自己設計格式。 A PROMPTS.md must log which agent, key prompts, resulting commits, and how you reviewed/edited the output — a ready-to-copy template is provided.

公開時機與抄襲防範 · Public Timing & Anti-plagiarism

建議繳交截止前 repo 設為 private，截止後才轉為 public——避免組間期中互相參考抄襲； 公開後我會直接 clone 下來，交由我這邊的 AI agent 進行分析與評分。 Keep repos private until the deadline, then make them public for the instructor's AI agent to clone and grade.

今天的重點 · Key Takeaways

這門課教你「如何讓機器辨認模式」；評分包含測驗、期中、期末與期末專案； 期末專案要求分組、善用 AI 智能體、Git 版控、公開 repo 並由 AI 評分。 下一堂課，我們就正式進入 §1 貝氏決策理論。 This course teaches machine pattern recognition; grading spans quizzes, exams, and an AI-assisted, Git-tracked, publicly graded final project. Next class: Bayesian Decision Theory.
