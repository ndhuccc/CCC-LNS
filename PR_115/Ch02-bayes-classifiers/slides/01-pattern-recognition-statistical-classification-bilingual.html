BIG QUESTION · 靈魂拷問
給電腦一堆線索，
它憑什麼敢拍板「這是 A 還是 B」？ Given a pile of clues, what gives a machine the right to declare “it’s A, not B”?

答案不只一種——有人講「成見＋證據」，有人直接硬切一刀，有人問鄰居，有人把世界摺到高維再切。There is no single answer: some combine prior & evidence, some cut a hard boundary, some ask neighbours, some lift the world to higher dimensions.

S1 · 引起動機 · MOTIVATE

分類是什麼？不只是貼標籤 What Is Classification? Not Just Labeling

分類就是「在不確定下做決定」的科學。輸入是特徵向量 $x \in \mathbb{R}^d$，輸出是離散標籤 $y \in \{C_1,\dots,C_K\}$。關鍵在於：不同家族對「不確定」有完全不同的建模方式。Classification = decision under uncertainty: input $x \in \mathbb{R}^d$, output label $y$. Families differ in how they model uncertainty.

PHILOSOPHY

兩條世界觀 Two worldviews

生成式 (Generative)：先學會「每類長什麼樣」$P(X\mid C_j)$，再用貝氏算後驗。Learn $P(X\mid C_j)$ per class, then posterior via Bayes.

判別式 (Discriminative)：不管怎麼生成，直接學邊界 $P(Y\mid X)$ 或決策函數。Ignore generation; learn $P(Y\mid X)$ or boundary directly.

BOUNDARY

三種邊界長相 Three boundary shapes

直線（LDA / Logistic / SVM 線性）、二次曲線（QDA / 核 SVM）、階梯狀（決策樹）。Linear, quadratic, staircase — each reflects an assumption about the world.

沒有萬能模型，只有「對的假設配對的資料」。No free lunch: right assumption must match the data.

INTUITION

一句話記住六大家族 One-liner per family

貝氏：成見＋證據；LDA/QDA：胖瘦決定直或彎；Logistic：直接算機率；KNN：問鄰居；樹/森林：官僚流程＋投票；SVM：留最寬安全島。Bayes priors+evidence; LDA/QDA covariance decides line/curve; Logistic direct prob; KNN neighbours vote; Trees bureaucracy+ensemble; SVM widest margin.

TRAP

先驗的威力 Power of priors

同一個 $x=5$，先驗 $0.5$:$0.5$ 時邊界在中間；先驗 $0.9$:$0.1$ 時後驗直接偏向多數——成見會吃掉證據。Same $x=5$: equal priors → boundary at centre; 0.9 vs 0.1 → majority dominates. Priors can swallow evidence.

直覺理解 · Intuition

把分類想成法庭：貝氏是「法官綜合前科（先驗）與現場跡證（似然）判案」；Logistic 是「陪審團只看現場投票給機率」；KNN 是「問隔壁鄰居你是哪幫的」；SVM 是「在兩幫之間劃最寬的無人區」。Courtroom: Bayes = judge (record + evidence), Logistic = jury voting prob, KNN = ask neighbours, SVM = widest no-man’s-land.

S2 · 維持注意 · SUSTAIN

1 · 貝氏家族：證據 × 成見 Bayes Family — Evidence × Prior

老祖宗 Thomas Bayes 留下一條「綜合判斷」公式：後驗 $\propto$ 似然 $\times$ 先驗。理論上這是無敵的最優分類器（Bayes Optimal），實務上難在估準 $P(X\mid C_j)$。Bayes rule: posterior $\propto$ likelihood $\times$ prior — optimal in theory, hard to estimate in practice.

貝氏定理 · Bayes' Theorem（式 9）

$$P(C_j \mid X=x) = \frac{P(X=x \mid C_j)\,P(C_j)}{P(X=x)}$$

分母 $P(X=x)=\sum_k P(X\mid C_k)P(C_k)$ 只是歸一化常數，決策時比大小 $ \arg\max_j P(C_j\mid X)$ 即可。Denominator is normalization; decide by $\arg\max$ posterior.

貝氏思維：成見與證據相乘後歸一化，再取最大後驗 · Bayes: prior × likelihood → normalized posterior → argmax

四個名詞一次記牢 · Four Terms

後驗 $P(C_j\mid X)$：看到 $x$ 後兇手是 $j$ 的機率（要算的答案）。
先驗 $P(C_j)$：還沒看現場前的成見。
似然 $P(X\mid C_j)$：若兇手是 $j$，現場長這樣的機率。
證據 $P(X)$：所有人留下此跡證的總機率（分母）。Posterior = answer; prior = belief before seeing $x$; likelihood = how typical $x$ is under $C_j$; evidence = normalizer.

為何需要 Naive Bayes？ · Why Naive?

特徵維度 $d$ 一高，$P(X\mid C_j)$ 估不準。乾脆假設特徵條件獨立：$P(X\mid C_j)=\prod_i P(X_i\mid C_j)$——天真但常很能打，尤其文本分類。High $d$ → density hard to estimate. Naive assumes conditional independence — often surprisingly strong, esp. text.

動手算算看 · Worked Example（$X=5$ 站在兩群正中間）

設 $C_1\sim\mathcal{N}(3,1)$、$C_2\sim\mathcal{N}(7,1)$，先驗各 $0.5$，常態密度 $f(x)=\frac{1}{\sigma\sqrt{2\pi}}\exp(-\frac{(x-\mu)^2}{2\sigma^2})$。Two Gaussians $\mathcal{N}(3,1)$ vs $\mathcal{N}(7,1)$, equal priors, test $x=5$.

① 似然 Likelihood

$P(X=5\mid C_1)=\frac{1}{\sqrt{2\pi}}e^{-2}\approx 0.054$
$P(X=5\mid C_2)=\frac{1}{\sqrt{2\pi}}e^{-2}\approx 0.054$
兩邊距中心皆 $2\sigma$，對稱相等。Symmetric: both $2\sigma$ away → equal.

② 證據與後驗

$P(X)=0.054\cdot0.5+0.054\cdot0.5=0.054$
$P(C_1\mid5)=\frac{0.054\cdot0.5}{0.054}=0.5$
$P(C_2\mid5)=0.5$ → 邊界恰在 $x^*=5$Equal priors → boundary at mid-point $x^*=5$.

💡 若先驗改為 $P(C_1)=0.9$，則 $P(C_1\mid5)=0.9$、$P(C_2\mid5)=0.1$——成見直接把邊界拉向少數類，即使似然相等也一面倒。With $0.9$ vs $0.1$ priors, posterior becomes $0.9$ — prior drags boundary toward minority.

怎麼讀圖 · How to Read

實線是「長相」似然；虛線是用先驗加權後的高度。黑虛線是後驗 $0.5$ 的決策邊界——等高點。先驗一偏，虛線高低立變，邊界跟著平移。Solid = likelihood shape; dashed = prior-weighted. Black dashed = posterior $0.5$ boundary — equal posterior. Shift prior → weighted heights move → boundary slides.

先驗陷阱 · Prior Pitfall

當 $P(C_1)=0.9$，即使 $x=5$ 距兩中心等距，後驗仍 $0.9$ 壓倒 $0.1$。在不平衡資料（如詐欺 1%），忽略先驗會造成災難性誤判。With $0.9$ vs $0.1$, same $x=5$ gives $0.9$ vs $0.1$ posterior. Ignoring priors on imbalanced data is catastrophic.

S2 · 幾何變形雙雄 · GEOMETRY

LDA 與 QDA：胖瘦決定直或彎 LDA vs QDA — Covariance Decides Linear or Curved

兩者皆假設每類是高斯，差在「胖瘦是否相同」。共變異數相等 → 線性超平面；各異 → 二次曲線。Both assume Gaussian per class; equal covariance → linear, unequal → quadratic.

LDA 線性判別 · Linear

假設 $\Sigma_1=\Sigma_2$（形狀、胖瘦、旋轉完全一致），僅中心不同。Assume shared $\Sigma$ — same shape, different centres.

  • 決策邊界為直線/超平面，公式線性於 $x$ (linear in $x$)
  • 參數少、穩健、適合小樣本 (few params, robust)
  • 若真實共變異數不同，會系統性偏誤 (biased if covariances differ)

$\delta_k(x)=x^T\Sigma^{-1}\mu_k-\tfrac12\mu_k^T\Sigma^{-1}\mu_k+\log P(C_k)$

兩類相減 $\delta_1-\delta_2=0$ 為線性方程。Difference is linear → straight boundary.

QDA 二次判別 · Quadratic

允許 $\Sigma_1\neq\Sigma_2$（每群胖瘦、旋轉各異）。Each class owns its $\Sigma_k$ — different spreads.

  • 決策邊界為拋物線/橢圓/雙曲線等二次曲線 (quadratic curves)
  • 更彈性，但參數多、易過擬合 (flexible, more params)
  • 每類需估 $O(d^2)$ 共變異數，小樣本慎用 ($O(d^2)$ covariance each)

$\delta_k(x)=-\tfrac12\log|\Sigma_k|-\tfrac12(x-\mu_k)^T\Sigma_k^{-1}(x-\mu_k)+\log P(C_k)$

含 $x^T(\Sigma_1^{-1}-\Sigma_2^{-1})x$ → 二次項。Quadratic term survives → curved boundary.

左：共變異數相同 → 橢圓等形狀，邊界筆直；右：胖瘦旋轉各異 → 邊界彎曲成二次曲線 · Left equal covariances → straight; right unequal → curved
S2 · 直球對決 · DISCRIMINATIVE

3 · Logistic 回歸：一顆神經元的誕生 Logistic Regression — A Single Neuron Is Born

不猜「資料怎麼長」，直接建模 $P(Y=1\mid X)$。把線性分數 $z=w^Tx+b$ 塞進 Sigmoid 壓到 $[0,1]$，輸出就是機率。Skip $P(X\mid C)$; model $P(Y\mid X)$ directly via sigmoid on linear score.

線性分數經 Sigmoid 壓縮為機率，邊界仍線性但輸出平滑可校準 · Linear score → sigmoid → calibrated prob

生成 vs. 判別 · Generative vs. Discriminative

貝氏/LDA 要估 $P(X\mid C)P(C)$ 兩大塊；Logistic 只估 $P(Y\mid X)$ 一塊，少做假設、少走彎路。Bayes/LDA estimate two pieces; Logistic estimates one — fewer assumptions.

直覺 · 神經元原型

這就是最老、最純的一顆人工神經元：線性加權 $+$ Sigmoid 非線性。疊很多顆就變深度網路。The oldest neuron: linear + sigmoid. Stack many → deep net.

優缺 · Pros & Cons

優：機率輸出可解釋、可校準；訓練凸優化、穩定。
缺：邊界仍線性，非線性資料需靠特徵工程或「升維＋核」。Pro: calibrated prob, convex. Con: linear boundary — need features/kernels for non-linear.

公式 · Sigmoid 與條件機率

$$\sigma(z)=\frac{1}{1+e^{-z}},\quad P(Y=1\mid x)=\sigma(w^Tx+b)$$

決策：$P\gt 0.5$ 判正類；損失為 Cross-Entropy（等價於最大似然）。Decide $P\gt 0.5$; loss = cross-entropy = MLE.

可調分數 vs. 機率對照（拉動 $w,b$ 感受邊界平移） · Score → Probability

S2 · 鄰舍多數決 · NEIGHBOURHOOD

4 · KNN 與度量學習：問鄰居與重新拉扯空間 KNN & Metric Learning — Vote & Reshape Space

KNN 零訓練、零參數（除 $k$）：新樣本看最近 $k$ 個鄰居多數決。但「近」的定義決定一切——於是有度量學習。Zero training: classify by $k$ nearest votes. But “near” is everything — hence metric learning.

KNN 多數決 · Majority Vote

超參只有 $k$。$k$ 小 → 靈活但吵；$k$ 大 → 平滑但鈍。常用歐氏/餘弦距離。Only $k$. Small $k$ = flexible but noisy; large $k$ = smooth but blunt.

  • 懶惰學習：訓練只存資料，預測才計算 (lazy: store, compute at query)
  • 維度詛咒：高維距離失真，需降維或度量學習 (curse of dimensionality)
  • 決策邊界呈「拼布狀」Voronoi 碎形 (piecewise Voronoi)

$k$ 選擇經驗法則 Rule of thumb

奇數避免平手；交叉驗證選 $k$；類不平衡時加權投票 $w=1/d$。Odd $k$ avoids tie; CV to tune; weight by $1/d$ if imbalanced.

度量學習 · Metric Learning

與其抱怨距離不準，不如學一個距離：把同類捏緊、異類拉開（如 Triplet Loss）。Don’t blame distance — learn it: pull same, push different (Triplet Loss).

  • 學習線性變換 $d_M(x,y)=\|Lx-Ly\|_2$ 或深度嵌入 $f_\theta(x)$ (learn $L$ or embedding $f_\theta$)
  • Triplet：$ \|f(a)-f(p)\|+m \lt \|f(a)-f(n)\|$ (anchor-positive vs anchor-negative)
  • 延伸至人臉辨識、檢索、對比學習 (face, retrieval, contrastive learning)

$\mathcal{L}_{\text{tri}}=\max\big(0,\; \|f(a)-f(p)\|^2-\|f(a)-f(n)\|^2+m\big)$

$m$ 為安全邊距 margin，與 SVM 異曲同工。$m$ is margin — same spirit as SVM.

左：KNN 拼布邊界；右：度量學習把空間「捏緊/拉開」，讓最近鄰真正反映語意相似 · Left Voronoi; right learned space makes neighbours meaningful
S2 · 官僚流程與投票 · RULES & VOTE

5 · 決策樹與隨機森林：官僚流程＋三個臭皮匠 Trees & Random Forest — Bureaucracy + Wisdom of Crowds

樹把特徵空間切成軸平行的小方塊；森林用 Bagging + 特徵抽樣種千棵樹再投票，大幅降變異而不增偏誤。Trees cut axis-aligned boxes; forest bags many trees and votes — variance down, bias stays.

樹：正交切割可解釋；森林：集成壓制過擬合 · Tree = interpretable cuts; forest = ensemble kills overfit

為何是「階梯」邊界 · Why Staircase?

每次只用一個特徵的閾值切割（如 $x_1\gt 5$），累積成水平/垂直的階梯狀邊界，高度可解釋。One feature per split → axis-aligned staircase, fully interpretable.

隨機森林為何有效 · Why Forest Works

單棵樹方差大、易過擬合；Bagging 讓每棵看不同子樣本與子特徵，去相關後平均→變異大幅下降。Single tree high variance. Bagging decorrelates trees; averaging slashes variance.

現代表格資料霸主 · Tabular King

在結構化表格資料上，樹/森林/梯度提升（GBDT）長期霸榜，且能自然處理缺值與混合特徵。On tabular data, trees/GBDT remain king; handle missing & mixed features naturally.

單棵樹 vs. 森林：偏誤-變異權衡示意 · Single Tree vs. Forest (bias-variance)

S2 · 極致美學 · MAX MARGIN

6 · SVM 與核技巧：最寬隔離帶＋維度跳躍 SVM & Kernel Trick — Widest Margin + Dimension Leap

最大化兩類間隙，解僅依賴「釘子戶」支援向量，具稀疏性 · Maximize gap; solution depends only on SVs (sparse)

核技巧：蚊香一刀切 · Kernel Trick

二維蚊香混疊時，映射 $\phi(x)$ 到高維 Hilbert 空間變線性可分。核 $K(x,z)=\langle\phi(x),\phi(z)\rangle$ 讓我們不必算 $\phi$ 本身。Entangled spiral in 2D → linear in high-D. Kernel computes inner product without explicit $\phi$.

常用：RBF $K=\exp(-\gamma\|x-z\|^2)$（無限維）、多項式、線性。Popular: RBF (infinite-D), polynomial, linear.

直覺：把紙揉起來切 · Scrunch the Paper

想像把混在一起的紅藍點畫在紙上，揉成球後從中間一刀切——攤平後在原平面看就是彎曲邊界。Draw mixed dots, scrunch paper, cut, unfold — curved boundary appears.

代價 · Cost

核矩陣 $O(n^2)$ 記憶體與計算；超參 $\gamma, C$ 敏感。大數據時代常被深度網路取代，但在中小數據仍極強。$O(n^2)$ kernel matrix; sensitive $\gamma, C$. Still strong on small/medium data.

公式 · 最大邊界

$$\min_{w,b}\tfrac12\|w\|^2\ \ \text{s.t.}\ \ y_i(w^Tx_i+b)\ge 1$$

對偶後僅內積 $\langle x_i,x_j\rangle$ 出現 → 可替換為核 $K(x_i,x_j)$。Dual uses only inner products → replace by kernel $K$.

核技巧：低維非線性 → 高維線性；RBF 甚至對應無限維空間 · Low-D non-linear → High-D linear; RBF is infinite-D

怎麼用這張圖選模型 · How to Pick

看兩軸：① 資料是否高維且特徵近獨立 → Naive Bayes；② 邊界是否線性 → LDA/Logistic/線性 SVM，否則 QDA/核 SVM/森林；③ 是否需要機率輸出 → Logistic；④ 是否需要可解釋規則 → 決策樹。Two axes: high-D independent? → Naive Bayes; linear boundary? → LDA/Logistic/linear SVM else QDA/kernel/forest; need prob? → Logistic; need rules? → Tree.

沒有萬能模型 · No Free Lunch

特徵多且近獨立 → Naive Bayes；
需平滑機率 → Logistic；
非線性混合 → 核 SVM / 森林；
要解釋規則 → 決策樹；
小樣本高斯 → LDA。Many independent features → NB; need prob → Logistic; non-linear → kernel/forest; need rules → tree; small Gaussian → LDA.

一句話複習邊界 · Boundaries in One Line

LDA 直、QDA 彎、決策樹階梯、SVM 最寬、KNN 拼布、Logistic 直但帶機率——每種邊界背後都是一種世界觀。LDA straight, QDA curved, tree staircase, SVM widest, KNN patchwork, Logistic straight+prob — each is a worldview.

本章金句 · Key Message

「分類不是選最炫的模型，而是選最誠實反映你對世界假設的那一把刀。」先問資料長什麼樣、要什麼輸出、要不要解釋——答案自然浮現。“Classify not with the flashiest model, but the one whose assumptions honestly match your world.” Ask data shape, desired output, need for explanation.

S3 · 思考測驗 · CHECK
