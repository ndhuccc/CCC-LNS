二次項消失的魔法
The Vanishing Quadratic

LDA 線性判別分析：共享 Σ，邊界退化成直線 LDA — shared covariance straightens the border.
One covariance for all classes; quadratics cancel, hyperplanes remain.
十個類別算十次反矩陣，風扇受得了嗎？Ten classes, ten inverses — can the fan survive?
S1 · 引起動機

退一步 · 海闊天空 Step back, breathe free

開場引言 · Opening

QDA 帥但貴：每類一個 $\Sigma_i$，十類算十次反矩陣，維度一高風扇狂轉；樣本不夠還會過擬合。QDA: flexible, hungry, overfits.

統計學家退一步：中心各長各的（$\boldsymbol{\mu}_i$ 不同），但身材胖瘦傾斜全一樣（共享 $\Sigma$）——催生常青樹 LDA，親眼看二次項被變不見。Share one Sigma; watch quadratics vanish.

S2 · 維持注意

蒸發魔法 · 三樣廢話扔掉 Three disposals

起點 · Start

$$g_i(\boldsymbol{x}) = -\frac{1}{2}(\boldsymbol{x} - \boldsymbol{\mu}_i)^T \Sigma_i^{-1} (\boldsymbol{x} - \boldsymbol{\mu}_i) - \frac{1}{2}\ln\vert\Sigma_i\vert + \ln P(\omega_i)$$

戴上緊箍咒 $\Sigma_1 = \Sigma_2 = \dots = \Sigma$，看它簡化。Force shared Sigma; simplify.

1

體積蒸發

$-\frac{1}{2}\ln\vert\Sigma\vert$ 各類相同，扣一樣＝沒扣，扔垃圾桶。Same fine for all: dropped.

2

二次蒸發

$\boldsymbol{x}^T\Sigma^{-1}\boldsymbol{x}$ 無 $\boldsymbol{\mu}_i$ 影子，各類平等，扔掉。No mu inside: dropped.

3

留下直線

$$g_i(\boldsymbol{x}) = \boldsymbol{w}_i^T\boldsymbol{x} + w_{i0}$$，$\boldsymbol{w}_i = \Sigma^{-1}\boldsymbol{\mu}_i$，$w_{i0} = -\frac{1}{2}\boldsymbol{\mu}_i^T\Sigma^{-1}\boldsymbol{\mu}_i + \ln P(\omega_i)$Linear survivor.

記住 · Remember

平方項 $x_1^2, x_2^2, x_1x_2$ 全軍覆沒——只剩一次方，幾何上就是直線／平面／超平面。Quadratics gone; hyperplane remains.

S2 · 維持注意

刀鋒幾何 · 朝向與位置 Direction and place

點法式 · Point-normal form

$$\underbrace{(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)^T \Sigma^{-1}}_{\boldsymbol{w}^T} \cdot \boldsymbol{x} + \underbrace{\frac{1}{2}\boldsymbol{\mu}_2^T \Sigma^{-1} \boldsymbol{\mu}_2 - \frac{1}{2}\boldsymbol{\mu}_1^T \Sigma^{-1} \boldsymbol{\mu}_1 + \ln\frac{P(\omega_1)}{P(\omega_2)}}_{w_0} = 0$$

$g_1 - g_2 = 0$ 寫成 $\boldsymbol{w}^T(\boldsymbol{x} - \boldsymbol{x}_0) = 0$。Tie in point-normal form.

刀鋒朝向 · Direction

  • 法向量 $\boldsymbol{w} = \Sigma^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)$ — normal vector
  • $\Sigma = \sigma^2I$ 時退化為連心線的垂直平分線 — perpendicular bisector
  • 相關時 $\Sigma^{-1}$ 扭轉方向，順橢圓長軸微調 — covariance twists it

刀鋒位置 · Position

  • 等先驗：切在幾何中點 $\frac{1}{2}(\boldsymbol{\mu}_1 + \boldsymbol{\mu}_2)$ — exact midpoint
  • $P(\omega_1) \gt P(\omega_2)$：$\ln\frac{P_1}{P_2} \gt 0$，刀往 $\omega_2$ 推 — majority pushes
  • 領地割讓給勢力大的一方 — land for the many

機制圖 · 蒸發＋刀鋒 Vanish and aim

軌道 B：蒸發三件套＋法向量中點推擠幾何 · 精準語意圖

易混點 · Confusion

LDA 省參數但假設強：若兩類胖瘦真不同，硬共享 $\Sigma$ 會欠擬合——QDA 與 LDA 是偏差／變異 trade-off，不是誰取代誰。Shared Sigma can underfit.

記住 · Remember

$\boldsymbol{w} = \Sigma^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_2)$ 定朝向、中點定位置、$\ln(P_1/P_2)$ 定推擠——三句話背下 LDA。Direction, place, push.

數值實戰 · 算出 x₁＋x₂＝4 Compute the line

設定 · Setup

$\boldsymbol{\mu}_1 = [1,1]^T$、$\boldsymbol{\mu}_2 = [3,3]^T$；$\Sigma = [[1,0.5],[0.5,1]]$；等先驗（對數比 $= 0$）。Two centers, one shared Sigma.

1

反矩陣

$|\Sigma| = 1-0.25 = 3/4$；$\Sigma^{-1} = [[4/3,-2/3],[-2/3,4/3]]$Det 3/4, invert.

2

法向量

$\boldsymbol{\mu}_1-\boldsymbol{\mu}_2 = [-2,-2]^T$；$\boldsymbol{w} = \frac{4}{3}[-1,-1]^T = [-4/3,-4/3]^T$Normal [-4/3,-4/3].

3

中點

$\boldsymbol{x}_0 = ([1,1]+[3,3])/2 = [2,2]^T$Midpoint (2,2).

4

點法式化簡

$-\frac{4}{3}(x_1-2)-\frac{4}{3}(x_2-2) = 0 \Rightarrow x_1+x_2 = 4$Line: sum equals 4.

驗收 · Check

$x_1 = 2 \Rightarrow x_2 = 2$ 穿中點；斜率 $-1$，左下 $R_1$ 右上 $R_2$——最堅固、最抗雜訊的一刀。Through midpoint, slope −1.
