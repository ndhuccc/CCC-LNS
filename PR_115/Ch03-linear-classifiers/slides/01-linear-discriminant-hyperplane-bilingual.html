3.2 線性判別函式與決策超平面 Linear Discriminant Functions & Decision Hyperplane

如果不計算繁瑣的先驗與機率密度函式，如何在特徵空間直接劃出一道清晰分界？本單元解構線性判別超平面：法向量 $\boldsymbol{w}$ 的方向決定分界朝向，偏置 $w_0$ 決定位置平移，代數值 $g(\boldsymbol{x})$ 精確度量空間距離！

為什麼權重向量 $\boldsymbol{w}$ 必然垂直於決策分界直線？
Why must the weight vector w be strictly orthogonal to the decision hyperplane?
超平面上任兩點相減的差向量必躺在分介面上，而兩式相減得到 $\boldsymbol{w}^\top(\boldsymbol{x}_1 - \boldsymbol{x}_2) = 0$！
內積為零證明 $\boldsymbol{w}$ 正交於分介面上所有切線方向——$\boldsymbol{w}$ 即為決策超平面的法向量！
01 / 幾何本質 · Geometric Principles

線性分類器的幾何骨幹：超平面與法向量 Geometric Backbone of Linear Classifiers: Hyperplanes & Normal Vectors

在特徵空間中，線性分類器透過最簡潔的幾何形狀——超平面（Hyperplane），將整個空間一分為二： $$g(\boldsymbol{x}) = \boldsymbol{w}^\top \boldsymbol{x} + w_0 = \sum_{i=1}^d w_i x_i + w_0 = 0$$ 在二維空間中超平面是一條直線，在三維空間中是一個平面，在 $d$ 維空間中則是 $d-1$ 維的超平面。

🧭 法向量 $\boldsymbol{w}$ 的方向決定性

若 $\boldsymbol{x}_1, \boldsymbol{x}_2$ 均位於超平面上，則滿足 $g(\boldsymbol{x}_1) = 0$ 且 $g(\boldsymbol{x}_2) = 0$： $$\boldsymbol{w}^\top \boldsymbol{x}_1 + w_0 - (\boldsymbol{w}^\top \boldsymbol{x}_2 + w_0) = \boldsymbol{w}^\top (\boldsymbol{x}_1 - \boldsymbol{x}_2) = 0$$ 差向量 $\boldsymbol{x}_1 - \boldsymbol{x}_2$ 平行於超平面，與 $\boldsymbol{w}$ 內積為零，證明 $\boldsymbol{w}$ 垂直於超平面，且恆指向正側 $g(\boldsymbol{x}) > 0$！

📏 偏置 $w_0$ 的位置截距性

原點 $\boldsymbol{x} = \mathbf{0}$ 代入判別函式得 $g(\mathbf{0}) = w_0$。因此原點到超平面的垂直幾何距離為： $$d = \frac{|w_0|}{\|\boldsymbol{w}\|}$$ 若偏置 $w_0 = 0$，則超平面必然精確穿過座標原點！$w_0$ 的大小實質控制了超平面偏離原點的位移量。

The weight vector w defines the hyperplane orientation as its normal vector, while bias w0 determines the intercept and distance from the origin.
02 / 向量幾何藍圖 · Visual Architecture

二維決策直線幾何剖析 (Example 3.1 藍圖) Geometric Anatomy of 2D Decision Boundary (Example 3.1 Blueprint)

代數距離與分類判決

判別函式 $g(\boldsymbol{x})$ 絕不僅僅輸出「正負號」，它的數值大小具備深刻的幾何距離意涵：

  • 點到超平面距離： 任意樣本點 $\boldsymbol{x}$ 到超平面的垂直距離為： $$z = \frac{|g(\boldsymbol{x})|}{\|\boldsymbol{w}\|}$$
  • 有號代數距離（Signed Distance）： 若去除絕對值，比值 $r = \frac{g(\boldsymbol{x})}{\|\boldsymbol{w}\|}$ 即代表該點沿法向量方向相對超平面的有號位移（正側為正，負側為負）。
  • Example 3.1 數值實戰： $\boldsymbol{w}=[1,1]^\top, w_0=-0.5$。 對於 $\boldsymbol{x}_A = [1, 1]^\top$，代入得 $g = 1.5 > 0$（歸類 $\omega_1$）；對於 $\boldsymbol{x}_B = [0.4, 0.05]^\top$，代入得 $g = -0.05 < 0$（歸類 $\omega_2$）。
The signed value g(x) directly reflects the directional orthogonal distance to the hyperplane scaled by the weight norm ||w||.
03 / 數學轉換 · Augmented Vectors

增廣特徵向量技巧：將仿射變換轉為原點超平面 Augmented Feature Vector Technique: Mapping to Origin Hyperplane

在原始 $d$ 維空間中，決策超平面帶有偏置項 $w_0$，屬於仿射集合（Affine Set）。透過引入增廣特徵向量（Augmented Feature Vector），可將數學形式大幅簡化為純粹的向量內積：

原始 $d$ 維特徵空間

特徵向量：$\boldsymbol{x} = [x_1, x_2, \dots, x_d]^\top$
權重向量：$\boldsymbol{w} = [w_1, w_2, \dots, w_d]^\top$
判別式：$g(\boldsymbol{x}) = \boldsymbol{w}^\top \boldsymbol{x} + w_0 = 0$（不一定透過原點）

增廣 $(d+1)$ 維特徵空間

增廣特徵：$\boldsymbol{y} = [1, x_1, x_2, \dots, x_d]^\top$
增廣權重：$\boldsymbol{a} = [w_0, w_1, w_2, \dots, w_d]^\top$
判別式：$g(\boldsymbol{y}) = \boldsymbol{a}^\top \boldsymbol{y} = 0$（必透過高維原點）

幾何性質 原始空間 ($d$ 維) 增廣空間 ($d+1$ 維)
決策分介面 可能不透過原點的仿射超平面 恆透過原點的線性子空間超平面
幾何約束 需同時最佳化斜率 $\boldsymbol{w}$ 與截距 $w_0$ 只需旋轉單一方向向量 $\boldsymbol{a}$
演算法意義 感知器需分別處理偏置更新 將偏置視為常數特徵 $y_0 = 1$ 的對應權重，統一更新規則

📌 本單元核心總結：決策超平面的幾何真諦 Key Takeaways: Hyperplane Geometry

  • 法向量正交性： 權重向量 $\boldsymbol{w}$ 必然垂直於超平面上任兩點連線，且永遠朝向正判別側（$g(\boldsymbol{x}) > 0$）。
  • 代數距離度量： 判別值 $g(\boldsymbol{x})$ 不僅給出二元符號，除以範數後的比值 $r = \frac{g(\boldsymbol{x})}{\|\boldsymbol{w}\|}$ 精確度量了點到超平面的空間幾何距離。
  • 偏置的截距意義： 原點距離為 $d = \frac{|w_0|}{\|\boldsymbol{w}\|}$；$w_0=0$ 時超平面精確透過原點。
  • 增廣空間統一性： 透過引入虛擬常數特徵 $y_0=1$，將帶有偏置的仿射超平面升維對映為高維過原點的線性超平面，為感知器演算法奠定優美的數學基石！
