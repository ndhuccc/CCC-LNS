獎懲式感知器：逐一樣本的線上學習變形 Reward-and-Punishment Perceptron: Sample-by-Sample Online Learning Variant

捨棄繁重的全域性誤判矩陣批次運算，改採「單樣本即時串流反饋」：
答對了什麼都不做（獎勵，零計算開銷）；答錯了立刻施加向量加減（懲罰，拉正超平面）！
連續完整掃描一輪無任何修正，即宣告全域收斂！

1. 線上串流更新
Online Streaming SGD

樣本一個接一個進來，無需保留全部資料，記憶體佔用恆為 $O(d)$。

2. 最高獎勵：靜默
Silent Reward Mechanism

當樣本預測正確時，權重分毫不動（$\Delta \boldsymbol{w} = \mathbf{0}$），計算極度省力。

3. 懲罰向量修正
Instant Weight Penalty

正類判負補加 $\rho\boldsymbol{x}$，負類判正扣除 $\rho\boldsymbol{x}$，單步即刻旋轉超平面。

4. Example 3.2 四步
4-Step Convergence

從零權重出發，歷經 2 次懲罰與 2 次獎勵，4 步鎖定對角分離線 $x_2 = x_1$。

核心思考問題 · CORE QUESTION

如果一個樣本已經分類正確，
為什麼感知器給予的最高獎勵是「什麼都不做」？

If a sample is already correctly classified, why is the supreme reward of the Perceptron to "do absolutely nothing"?

因為超平面的唯一目標就是「分開兩類」！
既然目前的權重已經滿足該點的幾何隔離條件，任何多餘的微調都只會引發其他點的無謂動盪；
「正確即免試，犯錯才揮尺」，造就了線上感知器極致優雅的計算效能！

線上學習機制：三態切換與更新公式

Online Learning Mechanism: Three-State Switching & Instant Updates
懲罰態 A：正類判負
False Negative ($\omega_1$)

條件：$\boldsymbol{x}_{(t)} \in \omega_1$ 但 $\boldsymbol{w}^\top(t)\boldsymbol{x}'_{(t)} \le 0$

$$\boldsymbol{w}(t+1) = \boldsymbol{w}(t) + \rho \boldsymbol{x}'_{(t)}$$

該加分卻未及格，把樣本向量加回，強力將超平面拉至該點後方。

懲罰態 B：負類判正
False Positive ($\omega_2$)

條件：$\boldsymbol{x}_{(t)} \in \omega_2$ 但 $\boldsymbol{w}^\top(t)\boldsymbol{x}'_{(t)} \ge 0$

$$\boldsymbol{w}(t+1) = \boldsymbol{w}(t) - \rho \boldsymbol{x}'_{(t)}$$

該扣分卻侵入正側，把樣本向量扣除，將超平面推到該點前方。

獎勵態：分類完全正確
Correct / Reward (Idle)

條件：$\boldsymbol{w}^\top(t)\boldsymbol{x}'_{(t)}$ 與目標類別符號一致

$$\boldsymbol{w}(t+1) = \boldsymbol{w}(t)$$

零計算、零修改，保持現狀，直接進入下一個樣本抽考。

教科書 Example 3.2：幾何演練與四步收斂軌跡

Example 3.2 Visualized: 2D Geometry & 4-Step State Timeline

Example 3.2 四步抽考時間軸

初始權重 $\boldsymbol{w}(0) = [0, 0, 0]^\top$，學習率 $\rho = 1$。

1
輸入 $\boldsymbol{x}_A = [-1, 0, 1]^\top \in \omega_1$： 內積 $= 0 \le 0$（誤判！）。
懲罰動作：加回樣本 $\boldsymbol{w}(1) = [0,0,0] + [-1,0,1] = [-1, 0, 1]^\top$。
2
輸入 $\boldsymbol{x}_B = [0, 1, 1]^\top \in \omega_1$： 內積 $= +1 > 0$（正確！）。
獎勵動作：不動 $\boldsymbol{w}(2) = [-1, 0, 1]^\top$。
3
輸入 $\boldsymbol{x}_C = [0, -1, 1]^\top \in \omega_2$： 內積 $= +1 \ge 0$（誤判！）。
懲罰動作：扣除樣本 $\boldsymbol{w}(3) = [-1,0,1] - [0,-1,1] = [-1, 1, 0]^\top$。
4
輸入 $\boldsymbol{x}_D = [1, 0, 1]^\top \in \omega_2$： 內積 $= -1 < 0$（正確！）。
獎勵動作：不動 $\boldsymbol{w}(4) = [-1, 1, 0]^\top$。
🎉 後續複驗：接著掃描第 5–8 步（再迴圈一輪），四個點均維持正確，連續 4 步零修正，演算法宣告收斂！最終解即為 $-x_1 + x_2 = 0$。

架構對比：線上獎懲式 vs 批次梯度感知器

Architectural Comparison: Online Stochastic vs Offline Batch Perceptron
線上學習（Online / Stochastic）的工程優勢
Engineering Advantages
  • 極低記憶體開銷：只需儲存當前樣本與權重向量，空間複雜度僅 $O(d)$，天然支援無限大資料串流。
  • 快速即時回饋：剛讀進第一個錯誤樣本就立刻轉動超平面，往往不需要看完整個資料集就能提早抵達解錐。
  • 現代深度學習基石：這正是現代 SGD (隨機梯度下降) 與 Mini-batch 訓練的雛形與精神源泉。
批次學習（Offline Batch）的特性
Batch Gradient Properties
  • 精確平滑的合成力矩：每一輪綜合所有誤判點的梯度總和，超平面的旋轉軌跡最為平滑穩定。
  • 計算等待時間長：每更新一次權重，都必須等待整批資料（百萬等級）完全載入與推論完畢。
  • 終止條件明確：只要統計得出的誤判集合 $Y = \emptyset$，立刻終止，無需額外一輪的複驗迴圈。

🎓 教授秘笈：線上獎懲機制與極簡工程美學 Master's Insights: The Biological Intuition of Online Reinforcement

1958 年羅森布拉特（Frank Rosenblatt）在紐約康乃爾航空實驗室打造第一臺感知器硬體 Mark I 時，採用的正是這種線上學習架構：

  • 仿生神經突觸塑性：赫布理論（Hebbian Learning）指出「神經元同步激發則突觸增強」。獎懲式感知器將此概念幾何化：刺激正確則保持穩態，刺激失誤則施加可塑性微調。
  • 現代隨機梯度下降 (SGD) 的先驅：當資料集膨脹到數億筆時，批次梯度（Batch Gradient）根本無法放進 GPU 記憶體。線上感知器所體現的「逐一樣本抽樣更新」思想，正是今日訓練大語言模型（LLM）所依賴的 SGD 最純粹的原型！
  • 終止條件的複驗機制：線上學習最容易犯的邏輯盲點是「以為只要當前樣本正確就結束了」。切記：必須完成完整一輪的大體檢，全體樣本均無一誤判，方可大功告成！
