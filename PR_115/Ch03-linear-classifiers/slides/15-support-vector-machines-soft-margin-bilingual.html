支援向量機（二）：不可分情況下的軟間隔與參數 C Support Vector Machines II: Soft-Margin SVM & Penalty Parameter C

真實世界資料充斥噪聲與類別重疊，強求零錯誤將導致超平面扭曲過擬合或根本無解！ 透過引入「鬆弛變數 $\xi_i \ge 0$」與懲罰超參數 $C$，軟間隔 SVM 在「最大化間隔裕度」與「懲罰違規樣本」之間達成完美的統計權衡。

⚖️ 裕度與錯誤權衡

代價函數 $\frac{1}{2}\|\boldsymbol{w}\|^2 + C\sum \xi_i$ 藉由超參數 $C$ 靈活控制模型對噪聲的容忍強度。

📦 對偶問題盒約束 (Box Constraints)

乘子被限制在 $0 \le \alpha_i \le C$，違規點 ($\xi_i > 0$) 之乘子硬頂在上界 $\alpha_i = C$！

🛡️ 鉸鏈損失 (Hinge Loss) 等價

等價於經驗鉸鏈損失加上 $\ell_2$ 權重正則化，建構出對離群值具備高度統計強健性的經典架構。

核心提問 · Core Question

真實資料往往混雜噪聲且互相重疊，
SVM 如何在「容忍少許錯誤」與「維持最大間隔」間取得完美平衡？

When Data Overlaps, How Does SVM Gracefully Trade Margin Width for Noise Tolerance?
$$ \min_{\boldsymbol{w}, w_0, \boldsymbol{\xi}} \frac{1}{2}\|\boldsymbol{w}\|^2 + C \sum_{i=1}^N \xi_i \quad \text{s.t.} \quad y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0) \ge 1 - \xi_i $$ 「超參數 $C$ 是寬容與嚴苛的調節器：小 $C$ 追求寬間隔容許違規，大 $C$ 嚴懲錯誤緊縮邊界！」

硬間隔 SVM 像一位吹毛求疵的完美主義者，只要一個噪聲點不可分就全盤宣告失敗；
軟間隔 SVM 則賦予每個樣本一個「免死金牌」鬆弛變數 $\xi_i$，在現實的重疊混沌中找到最具汎化力的黃金分割線！

幾何剖析 · Geometric Anatomy

1. 鬆弛變數 $\xi_i$ 與樣本的三種幾何歸宿

Slack Variables Formulation and the Three Geometric Roles of Training Points

當兩類分佈存在重疊時，不存在滿足 $y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0) \ge 1$ 的超平面。 引入鬆弛變數 (Slack Variable) $\xi_i \ge 0$，放寬邊界約束條件為：

$$ y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + w_0) \ge 1 - \xi_i, \quad \xi_i \ge 0 $$

根據點的實際位置，所有訓練樣本被精確劃分為三類幾何角色：

  • 正常安全點 ($\xi_i = 0$)：落在間隔帶外側或恰好在邊介面上。分類正確且完全不違規，$\alpha_i = 0$（內部點）或 $0 < \alpha_i \le C$（邊介面上）。
  • 帶內正確點 ($0 < \xi_i \le 1$)：落入間隔帶內部，但尚未越過中線 $\boldsymbol{w}^\top \boldsymbol{x} + w_0 = 0$。分類正確但違規侵入間隔，其對偶乘子頂到上限 $\alpha_i = C$！
  • 分類錯誤點 ($\xi_i > 1$)：越過中線落入敵對類別區域，造成實質分類錯誤，同樣頂到上限 $\alpha_i = C$。
對偶理論 · Dual Theory

2. 拉格朗日對偶問題與盒約束 (Box Constraints)

Lagrangian Dual with Upper Bound C and Hinge Loss Regularization

對偶問題的形式對比

構建廣義拉格朗日函數 $L(\boldsymbol{w}, w_0, \boldsymbol{\xi}, \boldsymbol{\alpha}, \boldsymbol{\mu})$ 並求偏導清零後，軟間隔對偶問題形式與硬間隔驚人地一致：

$$ \max_{\boldsymbol{\alpha}} \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j \boldsymbol{x}_i^\top \boldsymbol{x}_j $$ $$ \text{s.t.} \quad 0 \le \alpha_i \le C, \quad \sum_{i=1}^N \alpha_i y_i = 0 $$

唯一的關鍵差別在於：乘子 $\alpha_i$ 多了上界 $C$ 的盒約束 (Box Constraint)！ 當 $C \to \infty$ 時，上界消失，模型嚴格退化為硬間隔 SVM。

超參數 C 的極限行為比較

超參數特性 小 $C$ 值 (如 $C=0.1$) 大 $C$ 值 (如 $C=1000$)
間隔寬度 Margin 極寬（優先追求大間隔） 較窄（被迫收緊間隔）
對違規的態度 高容忍度，允許較多帶內點 零容忍，嚴懲任何違規
支援向量數量 較多（大量點 $\alpha_i = C$） 較少（僅邊界周邊關鍵點）
模型泛化風險 可能欠擬合 (Underfitting) 可能過擬合 (Overfitting)

結業精要總結 · Key Takeaways

軟間隔 SVM 核心要點回顧

軟間隔 SVM 透過引入鬆弛變數 $\xi_i \ge 0$ 與懲罰參數 $C$，賦予模型對噪聲與不可分資料的從容應對能力。 盒約束 $0 \le \alpha_i \le C$ 巧妙地防止單一離群點對超平面產生無限大的破壞力，成就了統計機器學習的基石典範。

鬆弛變數 $\xi_i$ 三重劃分

$\xi_i = 0$ 為帶外安全點；$0 < \xi_i \le 1$ 為帶內正確點；$\xi_i > 1$ 為跨線誤判點。

盒約束 $0 \le \alpha_i \le C$

自由 SV ($0 < \alpha_i < C$) 決定超平面偏置 $w_0$；受限 SV ($\alpha_i = C$) 為所有違規侵入點。

鉸鏈損失與 $\ell_2$ 正則

本質為結構風險最小化：$\min \sum \max(0, 1 - y_i f(\boldsymbol{x}_i)) + \frac{1}{2C}\|\boldsymbol{w}\|^2$。
