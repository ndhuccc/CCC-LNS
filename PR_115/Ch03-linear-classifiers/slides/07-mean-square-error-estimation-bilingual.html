均方誤差估計：從機率密度到最小均方誤差的轉向 Mean Square Error Estimation: Turning from Probability Densities to Minimum MSE

當特徵維度高聳、樣本數量有限時，估計全體聯合機率密度 $p(\boldsymbol{x}\mid\omega_i)$ 猶如大海撈針；
均方誤差 (MSE) 準則大膽發動典範轉移：繞過繁瑣的機率密度建模，直接令線性判別輸出逼近期望目標！
其代數極值條件 $\hat{\boldsymbol{w}} = R_x^{-1} E[\boldsymbol{x}y]$ 在幾何世界中，化身為極致優雅的子空間正交投影！

1. 估計典範轉移
Density vs MSE

不求全貌但求精準，放棄重建高維機率密度，直奔預測誤差平方最小化。

2. 自相關矩陣閉式解
Closed-Form Solution

最佳解 $\hat{\boldsymbol{w}} = R_x^{-1} E[\boldsymbol{x}y]$，以線性代數矩陣求逆直接秒解最優權重。

3. 正交投影定理
Orthogonal Projection

誤差殘差向量與輸入特徵子空間完全垂直：$E[\boldsymbol{x}(y - \boldsymbol{w}^\top\boldsymbol{x})] = \mathbf{0}$。

4. 多類別獨立拆解
Decoupled Multiclass

$M$ 類判別函數天然拆解為 $M$ 個相互獨立的純量 MSE 問題，平行獨立求解。

核心思考問題 · CORE QUESTION

如果算不出資料的真實機率分佈，
我們還能做出最優的分類決策嗎？

If estimating true probability densities is intractable, how can we still achieve optimal classification?

答案就是「以幾何正交取代統計積分」！
均方誤差 (MSE) 不問樣本從何而來，只問目標 $y$ 落在特徵子空間上的那道垂直陰影在哪裡；
投影落點之處，正是數學上唯一的誤差平方最小解！

典範轉移：從生成式機率密度到判別式均方誤差

Paradigm Shift: Generative Density vs Discriminative MSE
貝氏決策論路徑 (Generative Density)
Bayesian Density Estimation
  • 目標：先估計完整的先驗機率 $P(\omega_i)$ 與高維類別條件機率密度 $p(\boldsymbol{x} \mid \omega_i)$。
  • 瓶頸：「維度災難 (Curse of Dimensionality)」——高維特徵空間極其空曠，需要天文數字級別的樣本數才能精準估計分佈輪廓。
  • 非必要開銷：為了決定「分界線在哪裡」，卻耗費 99% 的精力去精確描摹「遠離邊界的密度細節」。
均方誤差估計路徑 (Discriminative MSE)
Mean Square Error Principle
  • 目標：直接定義期望目標標籤 $y \in \{+1, -1\}$（或 0/1），最小化輸出與目標之誤差平方。
  • 優勢：拋棄無關的密度細節，專注於端到端輸出逼近，計算形式為封閉解線性方程組。
  • 容錯性：即使兩類資料存在不可分離的重疊區域，MSE 依然能穩定給出幾何最優妥協面！

MSE 幾何真諦：特徵子空間上的正交投影

Geometric Interpretation: Orthogonal Projection onto the Feature Subspace

希爾伯特空間中的內積視角

在隨機變數構成的泛函空間中，定義內積為 $\langle u, v \rangle = E[u v]$：

正交性條件 (Orthogonality Principle)：

使平方距離 $\|y - \hat{y}\|^2 = E[(y - \boldsymbol{w}^\top\boldsymbol{x})^2]$ 最小的估計量，當且僅當殘差誤差 $e = y - \boldsymbol{w}^\top\boldsymbol{x}$ 與特徵子空間中的每一個基底向量 $x_i$ 都垂直正交：

$$E[x_i (y - \boldsymbol{w}^\top\boldsymbol{x})] = 0, \quad \forall i=1,\ldots,l$$

這完美解釋了為什麼解方程組會自然浮現出自相關矩陣 $R_x = E[\boldsymbol{x}\boldsymbol{x}^\top]$！

均方誤差正規方程推導與多類別推廣

Derivation of Normal Equations & Multiclass Decoupling
1. 極值微分與自相關矩陣
Gradient Derivation

代價函數定義為預測誤差的期望值：

$$J(\boldsymbol{w}) = E\left[\left(y - \boldsymbol{w}^\top\boldsymbol{x}\right)^2\right]$$

對權重向量 $\boldsymbol{w}$ 取梯度並令其為零向量 $\mathbf{0}$：

$$\nabla_{\boldsymbol{w}} J = -2 E\left[\boldsymbol{x}\left(y - \boldsymbol{w}^\top\boldsymbol{x}\right)\right] = \mathbf{0}$$ $$E[\boldsymbol{x}y] - E\left[\boldsymbol{x}\boldsymbol{x}^\top\right]\boldsymbol{w} = \mathbf{0} \implies R_x \hat{\boldsymbol{w}} = E[\boldsymbol{x}y]$$

若自相關矩陣 $R_x$ 非奇異（滿秩可逆），則存在唯一最佳閉式解：$\hat{\boldsymbol{w}} = R_x^{-1} E[\boldsymbol{x}y]$。

2. 多類別問題的獨立解耦
Multiclass MSE Decoupling

當面臨 $M$ 個類別時，我們為每個類別建立判別式 $g_i(\boldsymbol{x}) = \boldsymbol{w}_i^\top\boldsymbol{x}$，期望標籤向量為 One-Hot 編碼 $\boldsymbol{y} = [y_1,\ldots,y_M]^\top$：

$$J(W) = E\left[\|\boldsymbol{y} - W^\top\boldsymbol{x}\|^2\right] = \sum_{i=1}^M E\left[\left(y_i - \boldsymbol{w}_i^\top\boldsymbol{x}\right)^2\right]$$

驚喜的解耦性：矩陣損失可完美拆分為 $M$ 個獨立的純量 MSE 問題！每個類別的權重 $\boldsymbol{w}_i = R_x^{-1} E[\boldsymbol{x}y_i]$ 只需與該類的標籤向量單獨做一次相關性計算，無需複雜的聯合最佳化。

🎓 教授秘笈：正交投影的威力與代數優雅 Master's Insights: The Unreasonable Effectiveness of Orthogonal Projection

均方誤差 (MSE) 是從「機率論」跨入「線性代數幾何」的一道宏偉拱門：

  • 別為不重要的細節買單：高維空間中的密度估計往往是徒勞無功的，MSE 告訴我們：只要能將目標訊號 $y$ 垂直打在特徵向量張成的平面上，你就已經抓住了線性逼近的極限。
  • 正交就是最佳妥協：「為什麼是正交？」因為在畢氏定理的支配下，斜著切下去的線段永遠比垂直垂線長！當殘差 $e$ 與平面垂直時，它的歐氏長度達到全域最小值。
