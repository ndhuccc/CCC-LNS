CH03 · 知識點 02 / 18 · 線性分類器

感知器演算法：用錯誤驅動的疊代學習 Perceptron Algorithm: Error-Driven Iterative Learning & Torques of Misclassification

假定兩類模式具備線性可分性，感知器演算法透過錯誤集合 $Y$ 施加的實體力矩，反覆拉推超平面法向量 $\boldsymbol{w}$。 每一次權重修正，均將誤判樣本嚴格拖回正確半空間，直至達到零誤判 $Y = \emptyset$ 的全域性收斂解。

1. 線性可分公理
Linear Separability Axiom

存在理想權重 $\boldsymbol{w}^*$ 使兩類樣本格點滿足嚴格符號隔離：$\boldsymbol{w}^{*\top}\boldsymbol{x} > 0 \ (\forall \omega_1)$ 且 $\boldsymbol{w}^{*\top}\boldsymbol{x} < 0 \ (\forall \omega_2)$。

2. 感知器代價函式
Perceptron Criterion $J_P(\boldsymbol{w})$

$J_P(\boldsymbol{w}) = \sum_{\boldsymbol{x}\in Y} (\delta_x \boldsymbol{w}^\top \boldsymbol{x})$。僅誤判點計入損失，非負且僅在零錯誤 $Y=\emptyset$ 時取得全域最小值 0。

3. 梯度更新力矩
Gradient Descent Torque

更新式 $\boldsymbol{w}(t+1) = \boldsymbol{w}(t) - \rho_t \sum_{Y} \delta_x \boldsymbol{x}$。正類誤判加樣本，負類誤判減樣本，將法向量強行拉向正方向。

4. Example 3.1 驗證
Numerical Step Convergence

教科書範例 3.1 實證：初始超平面誤判 2 個點，經批次梯度修正一步旋轉為 $1.42 x_1 + 0.51 x_2 - 0.5 = 0$，達到零誤判收斂。

錯誤驅動幾何機制：力矩推拉與半空間修正

Error-Driven Geometric Mechanism: Torques of Misclassification
正類誤判 $(\boldsymbol{x}\in\omega_1, \boldsymbol{w}^\top\boldsymbol{x} \le 0)$
False Negative in Class 1

本應位於正半空間的樣本落入了負側。此時指標因子 $\delta_x = -1$。

$$\Delta \boldsymbol{w} = -\rho_t (-1) \boldsymbol{x} = +\rho_t \boldsymbol{x}$$

幾何效果：在權重向量上加上該點的坐標，法向量 $\boldsymbol{w}$ 往該點方向旋轉，使得更新後的內積 $\boldsymbol{w}(t+1)^\top \boldsymbol{x} = \boldsymbol{w}(t)^\top \boldsymbol{x} + \rho_t \|\boldsymbol{x}\|^2$ 數值大幅增加，強行將超平面拉過該點背後。

負類誤判 $(\boldsymbol{x}\in\omega_2, \boldsymbol{w}^\top\boldsymbol{x} \ge 0)$
False Positive in Class 2

本應位於負半空間的樣本侵入了正側。此時指標因子 $\delta_x = +1$。

$$\Delta \boldsymbol{w} = -\rho_t (+1) \boldsymbol{x} = -\rho_t \boldsymbol{x}$$

幾何效果：在權重向量上減去該點的坐標，法向量 $\boldsymbol{w}$ 遠離該點方向旋轉，使新內積 $\boldsymbol{w}(t+1)^\top \boldsymbol{x} = \boldsymbol{w}(t)^\top \boldsymbol{x} - \rho_t \|\boldsymbol{x}\|^2$ 數值大幅降低，將超平面推到該點的前方。

Example 3.1 數值解析與力矩平衡

在教科書範例中，初始權重 $\boldsymbol{w}(t) = [1, 1, -0.5]^\top$，學習率設定為 $\rho_t = 0.7$。

誤判點擴增向量代入：

  • $\boldsymbol{x}_1 \in \omega_1 \implies \delta_{x_1} = -1, \quad \boldsymbol{x}'_1 = [0.4, 0.05, 1]^\top$
  • $\boldsymbol{x}_2 \in \omega_2 \implies \delta_{x_2} = +1, \quad \boldsymbol{x}'_2 = [-0.2, 0.75, 1]^\top$
$$\boldsymbol{w}(t+1) = \begin{bmatrix}1\\1\\-0.5\end{bmatrix} - 0.7(-1)\begin{bmatrix}0.4\\0.05\\1\end{bmatrix} - 0.7(+1)\begin{bmatrix}-0.2\\0.75\\1\end{bmatrix} = \begin{bmatrix}1.42\\0.51\\-0.5\end{bmatrix}$$

驗證新超平面：代入 $\boldsymbol{x}_1$ 得到 $g(\boldsymbol{x}_1) = 1.42(0.4) + 0.51(0.05) - 0.5 = +0.0935 > 0$（成功翻轉為正！）；代入 $\boldsymbol{x}_2$ 得到 $g(\boldsymbol{x}_2) = 1.42(-0.2) + 0.51(0.75) - 0.5 = -0.4015 < 0$（成功翻轉為負！），所有點全部分類正確，$Y = \emptyset$ 終止。

感知器代價函式與梯度下降推導

Mathematical Derivation: Perceptron Criterion & Gradient Descent
1. 代價函式構造：為何處處非負？
Perceptron Criterion Construction

若定義代價為「誤判樣本數」，其函式由離散階梯組成，梯度處處為 0，無法進行數值最佳化。感知器改以誤判點到超平面的投影距離構造：

$$J_P(\boldsymbol{w}) = \sum_{\boldsymbol{x} \in Y} \left(\delta_x \boldsymbol{w}^\top \boldsymbol{x}\right)$$

當 $\boldsymbol{x} \in \omega_1$ 誤判時，$\boldsymbol{w}^\top \boldsymbol{x} \le 0$ 且 $\delta_x = -1$，乘積 $(-1)(\le 0) \ge 0$；
當 $\boldsymbol{x} \in \omega_2$ 誤判時，$\boldsymbol{w}^\top \boldsymbol{x} \ge 0$ 且 $\delta_x = +1$，乘積 $(+1)(\ge 0) \ge 0$。
因此，每一項恆為非負！$J_P(\boldsymbol{w}) \ge 0$，唯有 $Y = \emptyset$ 時達到全域最小值 0。

🎓 教授秘笈：感知器演算法核心思維總結 Master's Insights: The Mechanics & Philosophy of Perceptron Learning

感知器之所以成為機器學習發展史的奠基石，核心在於它展示了「從錯誤中自我校正」的極簡優雅幾何架構。請牢記以下四大核心心法：

  • 錯誤即力矩：分類正確的樣本是沈默的大多數，完全不施加任何力量；唯有犯錯的點會化身為「虛擬旋轉力矩」，把超平面的法向量 $\boldsymbol{w}$ 一點一滴扳向正確方位。
  • 代價函式的精妙平衡：$J_P(\boldsymbol{w}) = \sum_Y \delta_x \boldsymbol{w}^\top \boldsymbol{x}$ 不是測量幾何歐氏距離（那樣需要除以 $\|\boldsymbol{w}\|$ 導致非線性不可微），而是直接使用代數內積，既保證了分段線性的可微性，又完美提供了正比於偏離深度的回饋量。
  • 有限步收斂保證：只要樣本線性可分，不論初始權重 $\boldsymbol{w}(0)$ 在多偏僻的角落，演算法必定在有限步內完全終止於 $Y = \emptyset$（收斂證明見下一節 KP03）。
  • 死穴與演化伏筆：若資料集非線性可分（如 XOR），感知器將陷入無窮無盡的超平面迴圈震盪——這正是 1969 年明斯基（Minsky & Papert）重創神經網路的導火線，也是後續口袋演算法 (Pocket Algorithm) 與多層感知機 (MLP) 誕生的關鍵契機！
