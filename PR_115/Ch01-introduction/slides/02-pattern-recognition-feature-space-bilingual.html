起手痛點：直接比對整張圖，電腦會哭出來！ Why pixel-by-pixel comparison fails on medical images

大一新生的直覺 · Freshman's instinct

「老師，這很簡單吧？我寫個程式把兩張照片一個像素一個像素比對就好了啊！」

如果你這麼做，我保證你的電腦會直接哭出來！

為什麼像素比對必敗 · Why pixel comparison fails

一張醫學影像動輒幾千萬個像素，病人呼吸動一下、機器曝光強一點、角度偏一度，像素數值完全面目全非。

特徵 (x₁, x₂) A feature is a measurable, discriminative scalar.

高手的策略 · Expert strategy

高手從不直接比對整張圖，我們要當「特徵福爾摩斯」！ Never compare raw pixels — extract discriminative features first.

S2 · 維持注意

什麼是特徵？給每個病灶發一張「幾何身分證」 Two key features for breast tumor lesions

放射科醫師告訴我們兩個關鍵臨床現象：

  • 良性腫瘤 (Class A)：組織均勻、鈣化或密度集中，相對偏亮。 Benign: uniform, brighter texture.
  • 惡性腫瘤 (Class B)：組織壞死、邊緣浸潤、質地混亂，暗斑與亮斑交錯。 Malignant: chaotic, spotted texture.

① 特徵 x₁：平均灰階值

Mean Gray Level · μ

$$x_1 = \mu = \frac{1}{N}\sum_{i=1}^N I(p_i)$$

白話意涵：這個區域「整體到底有多亮」？數值越大越白。

Higher μ means a brighter region.

② 特徵 x₂：灰階標準差

Standard Deviation · σ

$$x_2 = \sigma = \sqrt{\frac{1}{N}\sum_{i=1}^N \bigl(I(p_i) - \mu\bigr)^2}$$

白話意涵：這個區域「質地到底有多混亂、斑駁」？數值越大黑白對比越劇烈。

Higher σ means more chaotic texture.

🎯 神奇的事情發生了 · The Magic

把 l = 2 個特徵垂直排排站，組裝成「特徵向量 (Feature Vector)」：

$$\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = \begin{bmatrix} \text{平均灰階} \\ \text{灰階標準差} \end{bmatrix}$$

原本複雜的二維影像病灶，瞬間被濃縮成 2D 平面座標上的一個小點 (x₁, x₂)！這就是病灶的「幾何身分證」。

A complex 2D lesion collapses to a single point in 2D feature space.

你看圖上，所有的 ∘ 幾乎都擠在右下角（較亮、較平整），所有的 + 都散佈在左上角（較暗、較混亂）。

A simple straight line splits two clusters — that's the classifier.

歷史病歷庫的 70 位病患，每張病灶算出一組 (x₁, x₂)，畫在座標圖上。

決策線：楚河漢界，把特徵空間切兩半 Decision Line — splitting feature space into two regions

這條直線把特徵空間硬生生切成兩大領地：

Decision Boundary · 線性決策邊界

線的右下方 → R_A

良性決策區：判斷為「良性病灶 (Class A)」。 Class A region (Benign)

線的左上方 → R_B

惡性決策區：判斷為「惡性病灶 (Class B)」。 Class B region (Malignant)

S2 · 維持注意

數學實質意涵：線性判別函數 Mathematical essence — Linear Discriminant Function

線性判別函數 · Linear Discriminant Function

$$g(\mathbf{x}) = w_1 x_1 + w_2 x_2 + w_0 = 0$$

w = [w₁, w₂]T：是這條線的法向量，垂直於分界線，直直指向判定為正（良性）的方向。 w: normal vector pointing toward the positive (benign) region.

w₀：是偏置常數，決定這條線在平面上的高低截距。 w₀: bias term that shifts the line.

🔢 具體數值代入 · Concrete example

假設最佳決策線方程式為：

$$g(x_1, x_2) = x_1 - 2x_2 - 20 = 0 \iff x_2 = 0.5\,x_1 - 10$$

這裡 w₁ = 1、w₂ = −2、w₀ = −20。

法向量長度為：‖w‖ = √(1² + (−2)²) = √5 ≈ 2.236。

實戰演示：新病患來了，動手算一次！ Hands-on — classify a new patient step by step

今天門診來了一位新病患，照了超音波，系統自動圈出病灶並測得：

未知樣本特徵向量 · Unknown Sample
$$\mathbf{x}^* = \begin{bmatrix} 65 \\ 18 \end{bmatrix} \quad (\text{平均灰階} = 65,\ \text{標準差} = 18)$$
1

代入 g(x)

把 (65, 18) 塞進判別函數：

g = 1·65 + (−2)·18 − 20

2

算術化簡

= 65 − 36 − 20

逐步減下來。

3

得出分數

g(x*) = +9

正數 (g > 0) 落在右下側。

4

判定結果

x* ∈ R_A

良性病灶 (Class A)！

📏 信心指標：到邊界的距離 · Confidence distance

點到邊界的垂直距離公式：

$$d = \frac{|g(\mathbf{x}^*)|}{\|\mathbf{w}\|} = \frac{|+9|}{\sqrt{5}} \approx \mathbf{4.02}$$

距離分界線很遠，代表系統非常有把握。

Larger |d| → higher classification confidence.

警惕！什麼叫「誤判」？在醫學上會出人命 Misclassification — the deadly danger

⚠ 殘酷真相 · Harsh truth

分類器給出的只是「預測」，絕不保證百分之百正確！

A classifier only predicts — it never guarantees 100% correctness.

舉一個真實案例：圖上有一顆惡性腫瘤病人（真實標籤是 +），組織剛好還沒大面積壞死，量出來的特徵是 (58, 17.5)：

誤判案例 · Misclassification Case
$$g(58, 17.5) = 58 - 2(17.5) - 20 = 58 - 35 - 20 = \mathbf{+3} > 0$$

🚨 偽陰性：會出人命的錯誤 · False Negative

天啊！算出來居然大於 0，被分類器判成了良性 ∘！

這就叫誤判 (Misclassification)！在醫學上這叫偽陰性 (False Negative)——病人體內明明是惡性腫瘤，機器卻跟他說「沒事，回家睡覺」。

False negative = missed malignant case → life-threatening!

一分鐘核心記憶卡 One-minute recap — four key takeaways

1️⃣ 特徵與特徵向量

特徵 x_i 是可被測量、具備鑑別力的一個數字。

特徵向量 x = [x₁, ..., x_l]T 是將 l 個特徵排成陣列，代表物件在 ℝl 特徵空間中的幾何座標點。

Feature: a discriminative scalar. Feature vector: a point in ℝl.

2️⃣ 分類器本體

在特徵空間中切出區域邊界的數學規則 g(x) = 0。

新樣本代入判別函數，正負號決定落入哪一區，數值絕對值反映幾何距離與判斷信心。

Sign of g(x) → region; |g(x)| → confidence distance.

3️⃣ 誤判的代價

任何分類器都只是統計推論，無法百分之百保證無誤。

在醫療應用中，控制「偽陰性（漏診）」遠比盲目追求整體準確率更為嚴肅。

In medical AI, controlling false negatives outweighs overall accuracy.

4️⃣ 四大核心關卡

特徵生成 → 特徵選擇 → 分類器設計 → 系統評估，貫穿全書的工程骨架！

Generation → Selection → Design → Evaluation — the engineering backbone.
